# 💘 연애조작단 2077: 오퍼레이션 큐피드

> 2077년, 출산율 0.008. 테크노킹 도람푸 3세의 특명으로 창설된 비밀기관 **큐피드局**의
> 공작요원이 되어, **도저히 이어질 리 없는 두 사람**을 기어이 이어붙여라.

three.js + Claude API로 만든 **B급 병맛 LLM 게임**. 서버 없음, 빌드 없음, GitHub Pages에서 그대로 돌아간다.

## 🎮 플레이 방법

1. 페이지 접속 → **Anthropic API 키**(`sk-ant-...`) 입력. **키가 없으면 게임이 아예 안 돈다.**
2. 신입 교육 슬라이드 5장 → 국장 브리핑
3. **상설 의뢰 대장 20건** 중 한 조합 선택
4. 작전 준비 3종 (스타일링 · 코칭 · 격려 연설) — **채점 없음. 전부 프롬프트 주입일 뿐이다.**
5. 문자 공작 4턴 → 대면 공작 5턴. 두 LLM 에이전트가 자동으로 대화하고, 심판 LLM이 **클라이언트의 매 발언만** 채점한다
6. 결과 편지 + 디브리핑 (놓친 취향과 턴별 판정 원장 전면 공개)

## 🧩 이 게임의 규칙 하나

**플레이어가 쓴 글은 채점되지 않는다.**

스타일링·코칭·격려 연설·무전 — 넷 다 점수가 없다. 시험이 아니라 **프롬프팅**이다.
당신이 쓴 문장은 클라이언트 AI의 시스템 프롬프트에 **그대로 주입**되고,
점수는 오직 **"그래서 그 인간이 실제 문자·대면에서 뭐라고 말했는가"** 로만 매겨진다.

그래서 준비를 대충 하면 점수가 깎이는 게 아니라 — **그 인간이 대화에서 알아서 망한다.**

| 레버 | 채점? | 실제로 하는 일 |
|---|---|---|
| 👔 **스타일링** | ❌ | 3D 아바타 스펙과 `outfitDesc`를 바꾼다. **대면 첫 순간에 타겟이 그걸 직접 보고 반응**하고, 거기서 판정이 붙는다 |
| 🎧 **코칭** | ❌ | 클라이언트 시스템 프롬프트에 통째로 삽입된다. 비우면 그 인간은 **약점대로 행동한다** |
| 🔥 **격려 연설** | ❌ | 출동 직전 한마디로 삽입된다. 사연을 진짜로 짚었는지는 **그 인간이 판단**한다. 비우면 **겁에 질린 채로 나간다** |
| 📻 **무전 개입** | ❌ | 다음 발언에 주입된다. **미확인 취향을 캐낼 유일한 수단.** 무전 없는 턴에 클라이언트는 새 화제를 열지 못한다 |

## ⚙️ 게이지는 딱 두 개

기획서 원문대로 **호감(Love point)** 과 **분위기(Mood point)** 만 있다.

| 게이지 | 의미 |
|---|---|
| 💗 **호감** | 승리 조건. 난이도별 성공선을 넘겨야 성사된다 |
| 😊 **분위기** | 호감 획득 **배율**(×0.3 ~ ×1.6). 낮으면 취향을 저격해도 찔끔 오른다. **0이 되면 상대가 자리를 뜬다** |

분위기는 **올릴 때만 포화**한다 (`1 - mood/130`). 이미 좋은 분위기를 더 끌어올리긴 어렵고, 떨어질 땐 그대로 떨어진다.

### 심판이 등급을 먼저 고른다

`-10~10` 스칼라만 요구하면 LLM은 판정을 **전부 +4~+6에 몰아넣는다**(실측: `hit` 51%).
그래서 스키마가 **등급을 먼저 강제**하고, 규칙 계층이 그 밴드로 클램프한다.

| 등급 | 호감 | 조건 |
|---|---|---|
| `critical` | +8~+10 | **미확인 취향 관통** 또는 관계의 근본 문제를 정면으로 뒤집음 |
| `hit` | +5~+7 | 취향 목록을 실제로 대화 주제로 끌어냄 |
| `ok` | +2~+4 | 맥락을 잘 받았지만 취향은 못 건드림. **잘 굴러가는 대화의 대부분** |
| `empty` | -1~+1 | 인사·자기소개·형식적 질문·반복. 애매하면 무조건 여기 |
| `backfire` | -5~-2 | 상대 말을 씹고 자기 얘기, 부담스러운 작업 멘트, 뜬금없는 화제 전환 |
| `redline` | -10~-6 | **지뢰**를 밟았거나 상대의 정체성·직업·신념을 깎아내림 |

여기에 **게이트가 규칙 계층에 박혀 있다** (`gateTier`) — 부탁이 아니라 강제다.

- 취향 목록을 실제로 건드리지 않았으면 아무리 대사가 멋져도 **`ok`가 상한**이다
- `critical`은 **미확인 취향**을 관통했을 때만 남는다 (알려진 취향이면 `hit`으로 강등)
- 이미 캔 취향 재탕은 `ok`로 강등
- 심판이 목록에 없는 취향 이름을 지어내면 적중으로 인정하지 않는다
- 지뢰를 밟으면 심판이 뭐라 하든 `redline`

### 난이도

| | 문자/대면 턴 | 무전 | 출발 호감/분위기 | 성공선 | 분위기 하한 | 턴당 감쇠 |
|---|---|---|---|---|---|---|
| 쉬움 | 4 / 5 | 1+2 | 10 / 55 | 45 | 25 | 호감 0, 분위기 +0.5 |
| 보통 | 4 / 5 | 1+2 | 6 / 46 | 52 | 33 | 호감 -0.5, 분위기 -0.6 |
| 헬 | 4 / 5 | 1+2 | 3 / 38 | 60 | 40 | 호감 -1.0, 분위기 -1.4 |

무전 배분(문자 1회 / 대면 2회)은 기획서 규정이라 난이도와 무관하게 고정이다.

### 미확인 취향은 대화로 캔다

타겟의 취향 중 일부만 의뢰서에 인쇄되어 있고, 나머지는 **미확인**이며 **개수만** 통보된다.
반대로 **💣 지뢰는 전부 공개**된다 — 알려줬는데 밟으면 그건 요원 탓이다.

타겟 에이전트는 두 번째 발언부터 아직 안 들킨 미확인 취향의 **실마리를 흘리도록** 지시받는다.
("…사실 저 밤에 좀 이상한 거 하긴 하는데, 아니 됐어요.")
그 실마리를 **무전으로 물고 늘어져야** 취향이 열린다. 세 턴 연속 실마리를 안 흘리는 것은 금지다.

## 🧠 구조

용어를 정확히 쓰자면 — `llm.js`는 **API 클라이언트 래퍼**이고,
에이전트들을 턴마다 물려 돌리는 **하네스는 `engine.js`**다.

| 파일 | 역할 |
|---|---|
| `js/couples.js` | **의뢰 대장 20건.** 손으로 쓴 고정 데이터 (인물·사연·취향·지뢰·아바타 스펙) |
| `js/llm.js` | Claude Messages API 래퍼: 전송, **프롬프트 캐싱**, 재시도/백오프, 구조화 출력, 거절 처리, 토큰·비용·캐시 집계 |
| `js/engine.js` | 공작 **하네스**: 클라이언트 · 타겟 · 심판을 턴마다 오케스트레이션. DOM을 모른다 |
| `js/scoring.js` | 게임 **규칙**의 순수 함수. tier 밴드/게이트, 분위기 배율, 승패, 디브리핑. LLM 없이 단독 테스트 |
| `js/prompts.js` | 모든 시스템 프롬프트 + JSON 스키마 ("카트리지") |
| `js/game.js` | 화면/입력 계층 |
| `js/avatar.js` | 스펙(JSON) → three.js 블록 아바타. **머리색 태그가 그대로 3D 머리색**이 되고, `species`가 실루엣을 바꾼다 |
| `js/audio.js` | WebAudio 8비트 BGM/효과음 (외부 파일 0개) |
| `vendor/three.module.min.js` | three.js r170 |

LLM 호출 지점: 국장 브리핑 · 스타일링 시공(스펙 변환) · 클라이언트 에이전트 · 타겟 에이전트 ·
심판(등급 + 취향 적중 + 지뢰 탐지) · 대면 첫인상 판정 · 대면 상황 생성 · 결과 편지.
우측 하단 **🛰 LLM 콘솔**에서 원본 요청/응답과 캐시 적중량을 볼 수 있다.

### 종족이 실루엣을 바꾼다

의뢰인 절반이 인간이 아니다. `species`가 `fish`면 아가미·측지느러미·꼬리가 붙고,
`lion`이면 갈기 링·귀·꼬리, `zombie`면 팔이 앞으로 뻗고 실밥이 박히고,
`vampire`면 송곳니와 망토, `alien`이면 눈이 머리 절반을 먹고, `robot`이면 액정 눈과 가슴 LED가 생긴다.

스타일링은 색·의상·액세서리만 바꾸고 **`species`는 절대 건드리지 않는다.**

## ⚡ LLM 호출 최적화

라이브 계측 기준 **한 판 31콜 · 약 130초 · $0.28** (Opus 5, effort low).

| 기법 | 효과 |
|---|---|
| **심판 ∥ 타겟 동시 발사** | 심판과 타겟 응답은 서로 독립이다. 턴당 순차 왕복 **3회 → 2회** (지연 -33%) |
| **프롬프트 캐싱** | 에이전트/심판 시스템 프롬프트는 턴마다 바이트 동일 → `cache_control` breakpoint. 실측 **입력 토큰의 2/3가 캐시 재사용**, 판당 **약 47% 비용 절감** |
| **대면 상황 프리페치** | 문자 마지막 턴의 판정/응답 배치에 같이 태운다 (왕복 1회 추가 절감) |
| **의뢰 대장 정적화** | 20쌍이 고정 데이터라 로스터 생성·아바타 스펙 변환 LLM 호출이 **0회**. 대장 화면이 즉시 뜬다 |
| **오프스크린 썸네일 1개** | 카드 40장에 WebGL 컨텍스트를 40개 잡으면 브라우저 상한(~16)에서 터진다. 렌더러 하나로 PNG를 구워 재사용 |
| **국장 브리핑 프리페치** | 교육 슬라이드를 보는 동안 백그라운드 수신 |
| **심판 컨텍스트 절단** | 판정에 넘기는 대화 로그를 최근 12줄로 자른다 |

## 🧪 테스트

```bash
npm test                                            # 규칙 계층 33개 회귀 테스트 (LLM 불필요, 즉시)
ANTHROPIC_API_KEY=sk-... npm run live               # 실제 API로 게임을 끝까지 돌리는 밸런싱 하네스
node tests/sim.mjs /tmp/live-results.json --grid     # 기록된 판정을 오프라인 리플레이 (API 0회)
ANTHROPIC_API_KEY=sk-... node tests/browser.mjs      # 실제 브라우저 E2E (three.js 렌더까지 검증)
```

`tests/live.mjs`는 요원 역할을 네 수준으로 나눠 실제로 플레이한다.

| 프로필 | 무엇 |
|---|---|
| `ace` | 요원 역할을 LLM이 맡는다. 의뢰서를 읽고 준비물을 짜고, 매 무전 기회에 실황을 보고 지시한다 (**미확인 취향은 안 보여준다** — 진짜 플레이어와 같은 정보만) |
| `good` | 사람이 성의 있게 쓴 수준의 고정 템플릿 + 일반적인 무전 |
| `lazy` | "옷" / "잘해라" / "화이팅". 무전 없음 |
| `none` | 아무것도 입력하지 않음 |

`tests/sim.mjs`는 라이브 판정 스트림을 저장해두고 상수만 바꿔 다시 흘려보내므로,
성공선 튜닝을 **API 호출 없이** 반복할 수 있다. `--grid`는 성공선 후보를 훑어 잘한 플레이와
대충한 플레이가 실제로 갈리는 지점을 뽑아준다.
