# 💘 연애조작단 2077: 오퍼레이션 큐피드

> 2077년, 출산율 0.008. 테크노킹 도람푸 3세의 특명으로 창설된 비밀기관 **큐피드局**의
> 신입 공작요원이 되어, 연애 경험 0인 국민이 짝사랑 상대에게 고백하게 만들어라.

three.js + Claude API로 만든 **B급 병맛 LLM 게임**. 서버 없음, 빌드 없음, GitHub Pages에서 그대로 돌아간다.

## 🎮 플레이 방법

1. 페이지 접속 → **Anthropic API 키**(`sk-ant-...`) 입력. **키가 없으면 게임이 아예 안 돈다.**
   의뢰인·아바타·대화·판정·결과가 전부 LLM 실시간 생성물이다.
2. 신입 교육 슬라이드 5장 (그동안 백그라운드에서 오늘자 의뢰서가 생성된다)
3. 의뢰서 3건(쉬움/보통/헬) 중 선택
4. **작전 준비 4종** — 이게 승부의 8할이다
5. 문자 공작 → 대면 공작 (두 LLM 에이전트가 자동 대화, 심판 LLM이 매 발언 채점)
6. 결과 편지 + 디브리핑 (놓친 취향까지 전부 공개)

`?fast=1`은 더 이상 없다. 턴 수는 난이도가 결정한다.

## ⚙️ 게임 규칙 (요약)

게이지 3개로 굴러간다.

| 게이지 | 의미 |
|---|---|
| 💗 **호감** | 승리 조건. 난이도별 성공선을 넘겨야 고백이 받아들여진다 |
| 😊 **분위기** | 호감 획득 **배율**(×0.4~×1.5). 낮으면 취향을 저격해도 찔끔 오른다 |
| 🔥 **용기** | 스태미나. 턴마다 닳고, 바닥나면 **패닉** — 분위기를 스스로 깎아먹는다 |

플레이어의 레버 4개가 각각 다른 지점에 꽂힌다.

| 레버 | 효과 |
|---|---|
| 👔 **스타일링** | 호감 출발선 + **호감 획득 배율**(난이도별 하한 ×0.4~0.7). 대면 첫인상에서 일회성 큰 스윙 |
| 🎧 **코칭** | 분위기 출발선 + **증감 비대칭**(나쁘면 잘 안 오르고 잘 깎임). 클라이언트의 **약점**을 봉인해야 한다 |
| 🔥 **격려 연설** | 용기 스태미나 총량 (12~100). 사연의 디테일을 짚을수록 높다 |
| 📻 **무전 개입** | 용기 회복 + 분위기/호감 전환. **미확인 취향을 캐낼 유일한 수단**. 막연한 응원은 분위기를 깎는다 |

난이도별 요구치:

| | 턴 | 무전 | 공개/미확인 취향 | 성공선 | 턴당 호감 감쇠 | 턴당 용기 소모 |
|---|---|---|---|---|---|---|
| 쉬움 | 9 | 2+3 | 3 / 2 | 45 | 0 | 1.2 |
| 보통 | 11 | 1+2 | 2 / 3 | 50 | 1.2 | 5.5 |
| 헬 | 12 | 1+2 | 1 / 4 | 78 | 3 | 6 |

시뮬레이션(각 400판) 기준 성공률 — **헬은 네 레버 중 하나만 빠져도 0%**다.

| 플레이 | 쉬움 | 보통 | 헬 |
|---|---|---|---|
| 만점 | 100% | 100% | 100% |
| 잘함 | 100% | 100% | 70% |
| 스타일링 누락 | 98% | 2% | 0% |
| 코칭 누락 | 100% | 71% | 0% |
| 연설 누락 | 100% | 95% | 0% |
| 무전 미사용 | 90% | 66% | 0% |
| 전부 안 함 | 0% | 0% | 0% |

미확인 취향은 **내용을 절대 공개하지 않는다.** 개수만 통보되고, 적중해도 "1건 적중"만 뜬다.
전체 내용은 작전 종료 후 디브리핑에서 공개된다.

## 🧠 구조

용어를 정확히 쓰자면 — `llm.js`는 **API 클라이언트 래퍼**이고,
에이전트들을 턴마다 물려 돌리는 **하네스는 `engine.js`**다.

| 파일 | 역할 |
|---|---|
| `js/llm.js` | Claude Messages API 클라이언트 **래퍼**: 전송, 재시도/백오프, 구조화 출력 파싱, 거절 처리, 토큰·비용 집계, 호출 로그 |
| `js/engine.js` | 공작 **하네스**: 클라이언트 에이전트 · 타겟 에이전트 · 심판 · 무전 판정을 턴마다 오케스트레이션. DOM을 모른다 |
| `js/scoring.js` | 게임 **규칙**의 순수 함수. 난이도 파라미터, 턴 적용, 승패 판정, 디브리핑. LLM 없이 단독 테스트 가능 |
| `js/prompts.js` | 모든 시스템 프롬프트 + JSON 스키마 ("카트리지") |
| `js/game.js` | 화면/입력 계층 |
| `js/avatar.js` | LLM이 뽑은 스펙(JSON) → three.js 블록 아바타. 외모 태그의 머리색이 그대로 3D 머리색이 된다 |
| `js/audio.js` | WebAudio 8비트 BGM/효과음 (외부 파일 0개) |
| `vendor/three.module.min.js` | three.js r170 |

LLM 호출 지점: 국장 브리핑 · 의뢰서 생성(난이도별 취향 개수 지정) · 외모→아바타 스펙 ·
스타일링 반영+채점 · 코칭 채점 · 격려 연설 채점 · 클라이언트 에이전트 · 타겟 에이전트 ·
심판(분위기/호감 델타 + 미확인 취향 적중 탐지) · 무전 정확도 판정 · 대면 상황 생성 · 결과 편지.
우측 하단 **🛰 LLM 콘솔**에서 원본 요청/응답을 볼 수 있다.

## 🔐 API 키

브라우저에서 `api.anthropic.com`으로만 전송된다(CORS 직접 호출). "키 저장" 체크 시 localStorage에 남으니
공용 PC에서는 체크하지 말 것. 저장소에 키를 커밋하지 말 것.
