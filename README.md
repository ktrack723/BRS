# 💘 연애조작단 2077: 오퍼레이션 큐피드

> 2077년, 출산율 0.008. 테크노킹 도람푸 3세의 특명으로 창설된 비밀기관 **큐피드局**의
> 신입 공작요원이 되어, 연애 경험 0인 국민이 짝사랑 상대에게 고백하게 만들어라.

three.js + Claude API로 만든 **B급 병맛 LLM 게임**. 서버 없음, 빌드 없음, GitHub Pages에서 그대로 돌아간다.

## 🎮 플레이 방법

1. GitHub Pages URL(또는 로컬 서버)로 접속
2. **Anthropic API 키**(`sk-ant-...`)를 입력하고 부팅 — **키가 없으면 게임이 아예 안 돈다.**
   이 게임의 모든 콘텐츠(의뢰인, 아바타, 대화, 판정, 결과)는 전부 LLM이 실시간 생성한다.
3. 의뢰서 3건 중 한 명을 선택
4. 컨설팅: 스타일링(태그) / 대화 코칭 / 격려 연설
5. 문자 공작 → 대면 공작: 두 LLM 에이전트가 자동으로 대화하고, 심판 LLM이 매 발언을 채점한다.
   위기 순간에 **무전 개입**(문자 1회, 대면 2회)으로 판을 뒤집어라.
6. 며칠 뒤 도착하는 편지로 고백 성패 확인

- `?fast=1` 쿼리를 붙이면 대화 턴이 짧아진다 (테스트용)

## 🔐 API 키 주의

- 키는 브라우저에서 `api.anthropic.com`으로만 전송된다 (CORS 직접 호출, `anthropic-dangerous-direct-browser-access`)
- "키 저장" 체크 시 localStorage에 저장되므로 공용 PC에서는 체크하지 말 것
- 키를 저장소에 커밋하지 말 것

## 🧠 구조 (LLM 하네스)

| 파일 | 역할 |
|---|---|
| `js/harness.js` | 브라우저용 Claude 하네스: fetch, 구조화 출력(json_schema), 재시도/백오프, 거절 처리, 토큰·비용 집계, 호출 로그 |
| `js/prompts.js` | 게임의 모든 시스템 프롬프트 + JSON 스키마 ("카트리지") |
| `js/game.js` | 상태 머신: 부팅 → 브리핑 → 스크리닝 → 컨설팅 → 문자 → 대면 → 결과 |
| `js/avatar.js` | LLM이 뽑은 스펙(JSON)으로 블록 아바타를 조립하는 three.js 뷰어 — 외모 태그의 머리색이 그대로 3D 모델 머리색이 된다 |
| `js/audio.js` | WebAudio 8비트 BGM/효과음 (외부 파일 0개) |
| `vendor/three.module.min.js` | three.js r170 (번들) |

LLM 호출 지점: 국장 브리핑 · 의뢰서 생성 · 외모 태그→아바타 스펙 변환 · 스타일링 반영+채점 ·
격려 연설 채점 · 클라이언트 에이전트 · 타겟 에이전트 · 심판(무드/러브 판정 + 숨겨진 취향 탐지) ·
데이트 상황 생성 · 최종 정산(성패 판정 + 편지). 우측 하단 **🛰 LLM 하네스 콘솔**에서 원본 요청/응답을 볼 수 있다.

## 🚀 배포

GitHub Pages: Settings → Pages → Deploy from a branch → 이 브랜치의 `/ (root)` 선택. 끝.

로컬 실행:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

(ES 모듈이라 file:// 로는 안 열린다)
