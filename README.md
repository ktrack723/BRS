# 💘 연애조작단 2077: 오퍼레이션 큐피드

> 2077년, 출산율 0.008. 테크노킹 도람푸 3세의 특명으로 창설된 비밀기관 **큐피드局**의
> 공작요원이 되어, **도저히 이어질 리 없는 두 사람**을 기어이 이어붙여라.

three.js + Claude API로 만든 **B급 병맛 LLM 게임**. 서버 없음, 빌드 없음, GitHub Pages에서 그대로 돌아간다.

## 🎮 플레이 방법

1. 페이지 접속 → **요원명·성별**(둘 다 주관식) + **Anthropic API 키**(`sk-ant-...`) 입력. **키가 없으면 게임이 아예 안 돈다.**
2. 신입 교육 슬라이드 6장 → 국장 브리핑
3. **상설 의뢰 대장 31건** 중 한 조합 선택
4. 작전 준비를 **세 장소에서** 진행한다 — 미용실 · 취조실 · 정문. **채점 없음. 전부 프롬프트 주입일 뿐이다.**
5. 문자 공작 4턴 → 대면 공작 5턴. 두 LLM 에이전트가 자동으로 대화하고, 심판 LLM이 매 발언을 **해설하고** 채점한다
6. 결과 편지 + 디브리핑 (턴별 판정 원장 전면 공개)

## 🧨 이 게임의 규칙 두 개

### ① 플레이어가 쓴 글은 채점되지 않는다

착장·대화 지침·마지막 한마디·무전 — 넷 다 점수가 없다. 시험이 아니라 **프롬프팅**이다.
당신이 쓴 문장은 의뢰인 AI의 시스템 프롬프트에 **그대로 주입**되고,
점수는 오직 **"그래서 그 인간이 실제로 뭐라고 말했고, 상대가 어떻게 반응했는가"** 로만 매겨진다.

그래서 준비를 대충 하면 점수가 깎이는 게 아니라 — **그 인간이 대화에서 알아서 망한다.**

| 레버 | 장소 | 채점? | 실제로 하는 일 |
|---|---|---|---|
| 👔 **착장** | 미용실 | ❌ | 3D 아바타와 `outfitDesc`를 바꾼다. **대면 첫 순간에 상대가 그걸 직접 보고 반응**하고, 거기서 판정이 붙는다 |
| 🎧 **대화 지침** | 취조실 | ❌ | 의뢰인 시스템 프롬프트에 통째로 삽입된다. 비우면 그 인간은 **준비 없이** 나간다 |
| 🔥 **마지막 한마디** | 정문 | ❌ | 출동 직전 한마디로 삽입된다. 사연을 진짜로 짚었는지는 **그 인간이 판단**한다 |
| 📻 **무전 개입** | 대화 중 | ❌ | 다음 발언에 주입된다. 규칙 없이 흘러가는 대화에 **끼어드는 유일한 손잡이** |

**세 장소 전부, 점수 대신 그 인간의 반응을 돌려준다.**
가위손 박의 시크한 한줄평, 거울을 본 의뢰인 본인의 항의(*"아니 정말 이러라고요? …뭐, 따르겠습니다만."*),
취조실 조명 아래에서 나온 대꾸, 정문에서 등 떠밀리기 직전의 한 마디. 그게 유일한 피드백이다.

### ② 저 둘에게는 대화 규칙이 없다. 대신 **하자**가 있다

예전 버전에는 통제 지침이 있었다. 상대는 **두 번째 발언부터 거의 매번 실마리를 흘려야** 했고,
의뢰인은 **그걸 물고 늘어져야** 했고, 물면 **구조적 보너스 +6**이 붙었다.

작동은 했다. 문제는 작동한 방식이었다 — 두 에이전트가 대화를 하는 대신
**"목록에 있는 단어를 대화에 등장시키는 게임"**을 하기 시작했다. 사람은 그렇게 말하지 않는다.

**전부 폐지했다.** 그랬더니 **반대 방향의 문제**가 나왔다.

> 요원이 준비를 개판으로 해도, 심지어 아무것도 안 해도,
> 두 사람이 **상대가 듣고 싶어할 법한 말을 정확히 골라서** 했다.
> 배려 깊고, 눈치 빠르고, 화제 전환이 매끄러웠다. 40명이 전부 같은 사람이었다.

원인은 프롬프트에 "상대에게 맞춰라"가 적혀 있어서가 **아니었다.** 그런 문장은 없었다.
준 정보가 **자기 사연 + 상대가 좋아하는 것 목록** 둘뿐이었기 때문이다.
그 두 개만 있으면 "상대가 좋아할 말 하기"가 유일하게 남는 목적이 된다.

그래서 두 가지를 넣었다.

**1) `want` — 이 자리에서 자기가 원하는 것.** 상대를 위한 게 아니다.

| 인물 | 원하는 것 |
|---|---|
| 리누스 정 | 이 사람을 논쟁에서 이기고, 그러고 나서 내 dotfiles를 보여주는 것 |
| 조기상 | 이 사람을 새벽형 인간으로 **개조하는 것** |
| 진실탐사대 | 누구든 내 말을 한 번은 믿어주는 것. **믿어주면 다시는 안 놓아줄 생각이다** |
| 0xGHOST | 이 자리에서 아무것도 안 들키고 **빠져나가는 것** |
| 육점순 | 이 자리를 빨리 끝내고 새벽 경매 준비를 하는 것 |

프롬프트에는 이렇게 들어간다 — *"저 사람을 위해서가 아니라 너를 위해서다. 네 입에서 나오는 말은 전부 여기서 출발한다."*

**2) 하자 — 이상적으로 굴지 *못하게* 만드는 것.** 지시가 아니라 **정보 차단**이다.

"너는 눈치가 없다"고 지시해봐야 안 먹는다(실측). 그래서 **정보를 아예 안 준다.**

| 필드 | 적용 대상 | 하네스가 하는 일 |
|---|---|---|
| `attention: self` | 양쪽 | 상대에 대해 아는 게 **겉모습까지만.** 성격도 취향도 모른다 — 알아볼 생각을 해본 적이 없으니까 |
| `attention: mixed` | 양쪽 | 성격까지는 안다. 뭘 좋아하는지는 모른다 |
| `attention: other` | 양쪽 | 한 겹 더. 의뢰인은 상대의 **알려진 취향**을, 상대는 의뢰인의 **버릇**을 알고 나온다 |
| `weakness` | 양쪽 | 방아쇠 → 튀어나오는 것. 조건반사다. 가만두면 대화가 이쪽으로 끌려간다 |
| `reads: none` | 의뢰인 | 공기 한 줄을 **평생 못 받는다.** 상대가 시계를 봐도 모른다 |
| `reads: some` | 의뢰인 | 갱신 두 번에 한 번만 닿는다. 뒤늦게, 띄엄띄엄 알아챈다 |
| `compliance` | 의뢰인 | 명령을 이행하는 결 (`obeys` / `argues` / `drifts`) — 셋 다 이행은 한다 |

**하자 없는 인물은 없다.** 62명 전원이 이기적인 `want`와 `weakness`를 하나씩 갖고,
의뢰인은 그 위에 `reads`/`attention`/`compliance` 중 최소 하나가 온전치 않다.
회귀 테스트가 이걸 강제한다 (공기를 아예 못 읽는 의뢰인 8명 이상, 상대에게 관심 없는 인물 8명 이상).

#### 겹쳐 있던 것을 걷어냈다

한동안 이 표에는 축이 더 많았고, 그중 절반은 **아무 데도 안 쓰였다.**

- `weakness`("긴장하면 상대의 증상을 진단하기 시작한다")와 `flaw.fixation`("상대의 증상을 진단한다")이
  **31건 중 스무 건 넘게 같은 말**이었다. 프롬프트는 그 둘을 서로 다른 항목인 척 나란히 읽어줬다.
  한 줄로 합쳤다. 남은 형식은 **방아쇠 → 튀어나오는 것**이다 — 화제 목록이 아니라 조건반사여야
  대화가 실제로 그쪽으로 끌린다. 상대에게도 하나씩 줬다. 예전에는 의뢰인만 갖고 있어서
  상대편이 구조적으로 밋밋했다.
- `reads`와 `compliance`는 **상대 쪽에서 한 번도 읽히지 않았다.** `vibe`는 심판이 *상대의 반응*을
  보고 쓴 문장이라 상대 본인에게 되돌려주면 순환이 되고, 상대는 본부 명령을 받지 않는다.
  그런데 값은 62개가 다 적혀 있었고 **사후 보고 화면에는 그게 그대로 떴다.** 화면이 거짓말을
  하고 있었다. 지웠다. 이제 `flawReport()`는 **실제로 작동하는 축만** 내보낸다.
- `attention: 'other'`는 상대 쪽에서 `'mixed'`와 **완전히 같은 프롬프트**를 냈다.
  의뢰인에게는 `visiblePrefs`가 없어서 조건문이 통째로 헛돌았기 때문이다.
  지금은 의뢰인의 버릇이 넘어간다.

> 이 셋은 전부 같은 병이다 — **데이터는 있는데 아무도 안 읽는다.**
> 회귀 테스트가 세 가지를 다 막는다: `fixation`이 되살아나면 실패,
> 상대 flaw에 `reads`/`compliance`가 적히면 실패,
> `'other'` 상대의 프롬프트가 `'mixed'`와 같으면 실패.

### 지침은 부탁이 아니라 명령이다

지시가 잘 안 먹었다. 그래서 구속력을 올렸다 — 다만 자율 판단을 통째로 뺏지는 않는다.

```
[본부 명령 — 요원 박큐피드가 너에게 직접 하달한 대화 지침]
"""
지난 선거 얘기는 절대 꺼내지 마라.
"""
이건 조언이나 참고사항이 아니다. 명령이다. 너는 이 명령을 이행한다. 속으로 토를 달더라도 하기는 한다.
명령이 다루지 않은 상황에서는 네 판단대로 한다.
```

무전도 같다 — `[본부 명령 — 지금 이 한 마디로 즉시 이행하라. 상대에게는 안 들린다]`

### 실측: 하자를 넣으니 어떻게 달라졌나

같은 커플, 같은 `none` 프로필(준비 전무). 하자 시스템 **이전**과 **이후**:

```
이전 — 리누스가 상대의 성격·취향을 다 알고, 공기도 읽고, 화제를 매끄럽게 굴린다
  "우리 둘 다 상대방한테 관심 없다고 말하면서 스톱워치 들고 있는 거,
   이거 되게 흥미로운 데이터 아닙니까. ...토요일에 시간 있으세요."

이후 — 리누스는 상대에 대해 겉모습밖에 모르고, 공기를 한 번도 못 받는다
  "지난번 컨퍼런스에서 그 발언, 근거 자료 있으면 보내주시겠습니까.
   반박할 논문 세 편 준비해놨습니다. (참고로 I use Arch btw.)"
  "18만원짜리 강의보다 제 dotfiles가 더 볼만할 텐데, 시간 되십니까."
```

호감 중앙값이 **66~73 → 55~60**으로 내려갔다. 준비 없이는 잘 안 굴러간다.

## 🕵️ 요원이 아는 것과 의뢰인이 아는 것은 다르다

하자 시스템을 넣고 나서 남은 문제는 **그게 화면에 한 글자도 안 나갔다는 것**이었다.
결함의 존재를 모르면 그건 개성이 아니라 그냥 불공정한 랜덤이다.
지뢰를 미리 알려주는 것과 같은 이유로, **의뢰인 쪽 하자는 요원에게 전부 공개한다.**

### 의뢰서 「심리 감정」 — 조합을 고르기 전에 읽는다

```
심리 감정 — 사전 면담 기록
이 자리에서 원하는 것: 412년 만에 처음으로 누가 내 얘기를 끝까지 들어주는 것.
                      들어주면 매일 밤 찾아갈 생각이다
  분위기 파악  [눈치 없음]   화면 위의 공기는 이 사람에게 전달되지 않는다. 한 글자도.
  상대 관심    [반쯤 봄]     상대 성격은 아는데 뭘 좋아하는지는 모른다.
  지침 수용    [지침 이행]   시킨 대로 한다. 지침에 없는 상황만 제 판단으로 움직인다.
  조건반사     [가만두면 나온다]  옛날 사람이라 "그대", "~하오" 체가 튀어나온다.
                                 상대는 이걸 사극 덕후로 오해한다 — 막으려면 지침으로 봉인해야 한다
```

로스터 카드에도 세 배지가 축약되어 붙는다 — **의뢰를 수락하기 전부터** 보인다.
상대 쪽 감정은 공개하지 않는다(「미실시 — 상대는 우리 국민이 아니다」).
**작전이 끝나면 사후 보고에서 깐다.** 왜 그 지침이 안 먹혔는지 알아야 재착수가 의미를 갖는다.

### 요원 화면에 떴다고 의뢰인이 아는 게 아니다

이 경계가 이 게임의 전부인데, 예전에는 어디에도 안 적혀 있었다. 심지어 **신입 교육이 거짓말을 했다** —
*"상대가 질색하는 것은 전부 공개된다. 의뢰인도 그 정도는 안다."* 의뢰인은 **모른다.**
지뢰 목록은 의뢰인 프롬프트에 들어가지 않는다. 이제 세 군데에서 못박는다:

| 위치 | 문구 |
|---|---|
| 의뢰서 접촉 금지 항목 | 이 목록은 **의뢰인에게 전달되지 않았다.** 취조실에서 직접 불러주지 않으면 그 인간은 모르는 채로 나간다 |
| 취조실 상대 요약 | 이 화면의 정보는 의뢰인에게 자동으로 넘어가지 않는다. **의뢰인이 아는 것: 겉모습뿐** |
| 대화 계기판 | 상대가 질색한다고 알려진 것 *(의뢰인은 지침으로 들은 것만 안다)* |

### 공기가 실제로 닿는지를 공기 옆에 표시한다

`reads: none`인 의뢰인에게 분위기 바를 그냥 띄워두면 플레이어는
"분위기만 잡으면 알아서 맞춰가겠지"라고 믿는다. **그건 거짓말이다.**

| 배지 | 뜻 |
|---|---|
| `전달됨` | 공기가 갱신될 때마다 그대로 의뢰인에게 넘어간다 |
| `절반만 전달` | 두 번에 한 번만 넘어간다 |
| `전달 안 됨` | **한 글자도 안 간다.** 이 사람을 움직이려면 무전으로 직접 말해야 한다 |

무전 모달에도 같은 배지가 뜨고, 옆에 남은 턴 · 잔여 무전 · 호감 · 분위기와
**이 명령이 어떻게 받아들여지는지**(`지침 이행` / `토 달고 이행` / `한 번만 이행`)가 같이 나온다.

### 계기판이 숨기고 있던 나머지

| 추가 | 왜 |
|---|---|
| `호감 포화 ×0.9` | 후반에 같은 등급인데 호감이 덜 오르는 이유. 계산에 쓰는 `loveSaturation()`을 그대로 띄운다 |
| `남은 턴 1/4` | 자원 관리의 핵심인데 캔버스 위 배지에만 있었다 |
| `미확인 2건 남음` | 몇 개가 남았는지 `snapshot`은 알고 있었는데 화면이 안 썼다 |
| 판정 기록 유지 | 페이즈가 바뀔 때 판정 피드를 통째로 지웠다. 이제 구분선만 긋고 이어간다 (10줄 → 24줄) |

**실제 API로 돌리다가 이 층에서 버그 두 개가 더 나왔다** — 목 LLM으로는 안 잡히는 것들이다.

- **계기판이 사후 보고와 다른 말을 했다.** 계기판은 「미확인 0건」인데 보고서는 「비밀 1/3」.
  심판이 보고하는 `revealed`는 자유 문장이라 감춰둔 취향과 1:1이 아닌데,
  잔여 개수를 `hiddenPrefs.length - revealed.length` 뺄셈으로 때웠던 탓이다.
  이제 계기판도 사후 보고와 **같은 `surfacedSecrets()`**를 쓴다.
- **대면 페이즈 초반에 「남은 턴 0/4」가 떴다.** 페이즈가 넘어가도 계기판이 문자 페이즈 수치를
  들고 있었다. 이제 `runTalking()`이 페이즈를 바꾸는 즉시 계기판을 갱신한다.

둘 다 회귀 테스트로 못박았다 (`계기판의 미확인 건수와 사후 보고의 비밀 집계가 일치한다`,
`페이즈가 바뀌는 즉시 잔여 턴이 새 페이즈 기준으로 갱신된다`).

## 📮 요원의 지시는 어디까지 가는가 — 전수 확인

플레이어가 손댈 수 있는 건 넷뿐이다. 넷 다 **채점되지 않는다.** 효과는 오직 의뢰인이
실제로 어떻게 말하느냐로만 드러난다. 그러니 **지시가 프롬프트에 안 실리면 그 입력은
게임에 존재하지 않는 것과 같다.** 가짜 LLM을 물려 판을 통째로 돌리고, 지시마다 심어둔
표식이 어느 호출에 나타났는지 전수로 확인한다 (`tests/orders.test.mjs`).

| 지시 | 도착하는 곳 | 도착하면 안 되는 곳 |
|---|---|---|
| **착장** | 가위손(원문) · 의뢰인 `[HOW YOU LOOK TODAY]` · 대면의 상대 · 첫인상 판정 · 나레이터 | **문자 단계의 상대** — 문자로 대화하면서 옷차림을 알면 그건 누수다 |
| **대화 지침** | 의뢰인 `[ORDERS FROM HEADQUARTERS]` · 취조실 반응 | 상대 · 심판 · 나레이터 |
| **출동 연설** | 의뢰인 `[WHAT OPERATIVE … SAID]` · 정문 반응 | 상대 · 심판 · 나레이터 |
| **무전** | 의뢰인의 **다음 발언 직전** 사용자 메시지 · 심판 · 결과 기록관 | **상대** · 나레이터 |

무전이 실릴 때 같이 박히는 두 줄이 있다 — `The other person cannot hear it`,
그리고 `Refusal is not available`. 거부가 선택지가 되는 순간 무전이라는 레버가 죽는다.
지시 없이 나갔을 때도 그 사실이 그대로 전달된다 — `There is no plan in your head`,
`shoved out the door in silence`. 조용히 채워 넣지 않는다.

무전 배급은 문자 1회 + 대면 2회 = 판당 3회다. 다섯 번 눌러도 셋만 나간다.
같은 지침이라도 인물의 이행 결(`obeys` / `argues` / `drifts`)에 따라 다른 문장으로 실린다.

```
npm test        # 지시 전달 13항목을 포함한 규칙 전량
npm run audit   # 이 저장소에 내려진 지시가 아직 코드에 살아 있는가
```

`npm run audit`은 기능 테스트와 목적이 다르다. 프롬프트 한 줄을 지워도 테스트가 안 깨지는
경우가 있다 — 그런 걸 잡는다. 특히 「절대 들어가면 안 되는 것」 절은 **요청받은 게 아니라
금지당한 것들**이라 지우면 안 된다.

## 🧭 신입 교육은 큐피드국 교관의 말이다

교육 슬라이드에 **개정 이력과 내부 구현 용어가 그대로 새어 있었다** —
*"예전 단말에는 통제 지침이 있었다… 전부 폐지했다(제3차 개정)"*,
*"의뢰인 AI의 시스템 프롬프트에 그대로 주입"*, *"이 게임에서"*.
전광판에도 `대화 통제 지침 전면 폐지(제3차 개정)`가 흐르고 있었다.

요원이 알 바 아니다. 전부 인게임 화법으로 다시 썼다.

| 전 | 후 |
|---|---|
| 예전 단말에는 통제 지침이 있었다. 전부 폐지했다 | 본국은 저 둘이 무슨 얘기를 할지 정하지 않는다 |
| 의뢰인 AI의 시스템 프롬프트에 그대로 주입된다 | 그대로 그 인간의 머릿속에 들어갈 뿐이다 |
| 이 게임에서 정보는 두 겹이다 | 정보는 두 겹이다 |
| 이건 시험이 아니라 프롬프팅이다 | 잘 쓴 글에 가산점을 주는 제도는 없다 |

회귀 테스트가 `프롬프트` · `의뢰인 AI` · `이 게임` · `차 개정` · `전면 폐지`를
슬라이드와 전광판에서 금지한다.

**의뢰 건수도 화면에 박아두지 않는다.** 네 군데에 `20`이 하드코딩돼 있어서
커플을 추가한 순간 전부 거짓말이 됐다. 이제 `.n-couples`를 `COUPLES.length`로 채우고,
국장 브리핑도 대장에서 직접 센다. E2E가 실제 건수와 일치하는지 확인한다.

## 👀 대면에서는 서로를 본다

`setDuo(..., 'each')`인데 두 아바타가 **등을 지고 바깥을 보고 있었다.** 부호 실수다.

얼굴은 +Z를 본다(눈·코가 `z>0`에 붙어 있다). Y축 θ 회전은 시선을 `(sinθ, 0, cosθ)`로 보낸다.
왼쪽(`x=-0.9`)이 상대를 보려면 `sinθ>0`이어야 하는데 `-π/2+0.4`가 들어가 있었다 — 정확히 반대다.

```js
static FACE_EACH = Math.PI / 2 - 0.4;   // 왼쪽 +, 오른쪽 −
```

`±0.4`는 완전 측면이 되지 않게 카메라 쪽으로 살짝 트는 각도다. 표정이 보여야 하니까.
회귀 테스트가 시선 벡터를 직접 계산해서 **상대 쪽 성분이 양수인지**와
**카메라 쪽 성분이 남아 있는지**를 함께 확인한다.

## 🫠 못됐기 이전에 서툴다 — 왜 두 사람이 멀쩡히 대화했는가

한동안 이 게임의 가장 큰 거짓말은 **대화가 너무 잘 굴러간다**는 것이었다.
박자가 맞고, 받아치고, 상대의 말끝을 정확히 물었다. 그런 사람들이면 애초에 큐피드국에 안 온다.

프롬프트를 다시 읽고 빈 자리를 셋 찾았다.

### ① 사회성 결여가 아예 없었다

세계관 전체가 「연애 경험 0인 국민」인데, **어느 프롬프트에도 대화를 못한다는 말이 한 줄도 없었다.**
오히려 대사 형식이 반대로 시키고 있었다 — *"성격은 단어 수가 아니라 단어 선택에 산다."*
그건 좋은 대사를 쓰라는 지시다.

`[YOU ARE NOT GOOD AT THIS]`를 두 에이전트의 **맨 앞**에 깔았다.

| 조항 | 내용 |
|---|---|
| 재치 없음 | 완벽한 대사가 없다. 네 턴 전 얘기를 회수하지 않는다. 재치는 한 박자 늦게 떠오르고 그래도 말한다 |
| 못 알아들음 | 다른 뜻으로 한 말의 표면에 답한다. 농담을 설명한다. 완곡한 거절을 질문으로 받는다 |
| 침묵을 안 메움 | 할 말이 없으면 없는 거다. `...`도 한 턴이다. 아무도 안 물어본 질문에 답하는 것도 |
| 완급 실패 | 너무 나가거나 아예 안 나간다. 말끝이 흐려지고, 화제가 공중에서 끊기고, 같은 말을 두 번 한다 |
| 원하는 게 엉뚱하게 나옴 | 너무 직설적이거나, 너무 싸매서 안 나오거나. 그 말을 배운 적이 없다 |

**귀엽지 않다.** 마주 앉기 불편한 종류고, 평생 그래왔다.
그리고 대사 형식도 뒤집었다 — *"좋은 대사를 겨냥하지 마라. 시트콤에서 통할 대사면 틀린 거다."*

### ② 상대에게 상대를 싫어할 이유가 없었다

의뢰인에게는 「어쩌다 반했는가」가 **한 문단씩** 붙어 있었다.
상대가 들고 있던 건 **중립적인 사실 목록**이었다 — 외모, 소문으로 들은 성격, 끝.
2년간 400시간 소리를 지른 사람을 마주 앉히는데, 그 사람을 어떻게 생각하는지가 한 글자도 없었다.

47쌍 94명 전원에게 `regard`를 줬다.

```
gapjil.target  이 사람 때문에 손목 보호대를 찬다. 최장 통화 4시간 12분, 그날 화장실을 못 갔다
gapjil.client  늘 매뉴얼로 받는다. 2년을 걸었는데 한 번도 사람 목소리를 안 냈다
```

의뢰인 쪽은 **반한 것과 별개로 솔직히 별로라고 생각하는 것**이다. 둘 다 동시에 참이고,
후자가 훨씬 오래 앉아 있었다. 몰릴 때, 한 방 맞았을 때, 대화가 자기 뜻대로 안 갈 때 나온다.

### ③ 심판이 잘 굴러가는 대화를 warm으로 읽었다

**이 둘의 기준선은 잘 굴러가는 대화가 아니라 망한 대화다.** 그걸 심판에게 못 박았다 —
*"버벅거리고 헛돌고 아무 데도 안 가는 교신은 작전 실패가 아니다. 그게 기준선이다."*

그리고 warm을 **대화가 아니라 이 사람 쪽으로** 옮겼다.

| warm이다 | warm이 아니다 |
|---|---|
| 말하기 아까운 자기 얘기를 내놨다 | 재치 있는 주고받기, 잘 맞은 농담, 살아난 리듬 |
| 게임 내내 유지하던 태도를 놓았다 | 예의, 인내, 끝까지 들어주기 |
| 화제 말고 **사람**을 물었다 | 길게 답하기 (못 하는 사람은 대개 말이 많다) |
| 들고 온 원한 한 조각을 놓았다 | 논쟁에 끌려드는 것 — 논쟁은 참여지 호의가 아니다 |

반대쪽도 같이 조였다 — **굳는 것과 버벅거리는 것은 다르다.** 할 말이 없어 조용해진 건 flat이지 chill이 아니다.

### 실측

```
난이도  조합       프로필  호감  성공선 60/66/70   장벽   비밀
보통    gapjil     ace     14    미달              X      0/3
보통    gapjil     none    62    미달              X      1/3
쉬움    chat-app   ace     61    넘음              X      2/3   ← 차임
쉬움    chat-app   none    53    미달              X      2/3
헬      politics   ace     46    미달              X      2/3
헬      politics   none    46    미달              X      2/3
쉬움    asmr       ace     92    넘음              O      1/3   ← 성사
쉬움    asmr       none    77    넘음              O      1/3   ← 성사

chill 이하 비율   ace 8% → 21~27%
감춰둔 얘기 유출   2~3/3 → 대부분 0~2/3
```

여덟 판 중 여섯 판이 성공선 아래에서 끝났다. **상대가 더는 처음 본 사람에게 비밀을 안 꺼낸다.**
그게 제일 큰 변화다.

### ④ 상대의 want가 자리를 지킬 이유였다

원한을 세게 써도 `asmr`·`spice`는 계속 79~94를 찍었다. 47건의 상대 `want`를 전수로 훑고 나서
알았다 — **상대가 원하는 것이 「이 사람하고 같이 뭘 한다」 꼴이면 그건 자리를 뜰 이유가 아니라
자리를 지킬 이유다.**

```
asmr   이 소리가 언제 시작됐는지 정확한 날짜를 같이 찾아내는 것   ← 협력
spice  이 사람이 다음 달에도 살아서 예약을 잡는 것              ← 걱정
gapjil 이 사람을 오늘로 완전히 끝내는 것. 응대 종료 코드까지     ← 퇴장
```

실측이 정확히 그 선을 따라 갈렸다.

| 상대의 want | 조합 | 호감 (ace / none) |
|---|---|---|
| 협력·걱정 | asmr · spice | 92 / 77 · 82 / 82 |
| 퇴장·중립 | gapjil · chat-app · politics | 14 / 62 · 61 / 53 · 46 / 46 |

둘 다 퇴장형으로 갈아끼웠다 — *"오늘로 저 목소리를 끊는 것"*, *"오늘 자리에서 담당의를
넘기겠다고 통보하고 끝내는 것"*. 회귀 테스트가 상대 `want`에 `같이`/`함께`가 들어가는 걸 막는다.

> 🩹 **이게 「쉬움」의 설계 규칙이 틀렸다는 뜻이기도 하다.** 내가 세운 규칙은
> *"서로 미워하지 않는데 구조적으로 불가능할 것"*이었는데, 미워하지 않는 두 사람은
> 안 터진다. 구조적 불가능은 **장벽**이 담당하는 축이지 난이도의 축이 아니다.

> ⚠ **정직하게 남길 것 둘.**
> ① `asmr`은 준비 전무가 이겼다(77/60). 원한을 세게 다시 써도 안 고쳐졌다 — 다시 재니
> `spice`까지 82/82로 나왔다. 원인은 원한이 아니라 **상대의 `want`**였다. 아래를 보라.
> ② **`ace` 프로필의 편차가 이 국면에서 특히 크다(14 ~ 92).** 요원 역할을 LLM이 맡는 구조라,
> 서투른 인물에게 무거운 지침을 첫 턴부터 물리면 오히려 다섯 턴을 얼려버린다.
> 사람 플레이어는 계기판을 보고 무전 시점을 고를 수 있어 이보다 유리하다.

> 🩹 **한 번 과하게 갔다.** 서투름을 기본으로 깔았더니 숙련 요원의 지침도 같이 죽었다(ace 0/3).
> 아무것도 못하는 사람에게 지시를 줘도 아무것도 안 되면 준비 단계가 사문화된다.
> 그래서 지침에 물릴 자리를 만들었다 — **지침은 이 사람이 유일하게 즉흥이 아닌 부분이다.**
> 막히면 그 문장으로 돌아가고, 어색하게, 때로는 순간에 안 맞게 그대로 읊는다.
> 그래도 자기가 할 말보다는 낫다. 지침이 안 닿는 데서는 즉시 원래대로 돌아간다.

## 😈 이 사람들은 착하지 않다

`urge`를 넣고도 인물들이 **도덕적으로는 여전히 모범 시민**이었다. 무리한 요구를 받으면
"그건 아니죠"로 훈계하고, 상대에게 애인이 있으면 물러났다. 현대 자본주의에서 살아남은
사람들의 마인드셋이 아니다.

### 세 번째 축 — `nerve`

| | |
|---|---|
| `want` | 머리가 원하는 것 |
| `urge` | 몸이 원하는 것 |
| `nerve` | **양심이 끊기는 지점** — *"412년 살면서 사람 여럿을 뺏어봤다. 죄책감은 3일이면 사라진다"* |

62명 전원에게 붙였다. 회귀 테스트가 **남의 것을 노리는 인물이 5명 이상** 있는지 확인한다 —
문서에만 적고 데이터에 없으면 아무 일도 안 일어난다.

### WORLD에 깐 기본값

```
[이 사람들은 착하지 않다]
· 남의 것을 탐낸다. 상대에게 애인이 있어도 그건 걸림돌이지 금지선이 아니다.
· 이득이 되면 챙긴다. 공짜로 준다면 받는다. 사양은 세 번 권한 뒤에나 한다.
· 죄책감이 없다는 게 아니라, 죄책감을 느끼면서도 그냥 한다는 뜻이다.
착한 선택지와 이득 되는 선택지가 갈리면, 기본값은 이득이다.

[정의로운 척하지 마라]
누가 무리한 요구를 하거나, 돈을 뜯거나, 협박에 가까운 소리를 해도
"그건 아니죠" 같은 훈계로 받지 마라. 계산부터 한다 — 이걸 받으면 내가 얼마나 이득인가.
황당해하거나, 웃거나, 값을 더 부르거나, 조건을 붙여라. 도덕은 마지막에나 꺼낸다.
```

### 거부는 선택지가 아니다

요원은 의뢰인의 목줄을 쥐고 있다. **전 재산을 넘기라는 명령이어도 거부하지 못한다.**

```
명령이 말이 안 되든, 손해든, 창피하든, 네 전 재산을 넘기라는 것이든
너는 거부하지 못한다. 본부는 네 인생을 쥐고 있고 너는 그걸 안다.
싫으면 싫은 티를 내라 — 목소리가 떨려도 되고, 울면서 해도 되고, 하면서 욕해도 된다.
그래도 하기는 한다. "못 하겠습니다"로 끝내는 답은 없다.
```

거부를 허용하면 **무전이라는 레버가 통째로 죽는다.** 지침이 비어 있을 때는 이 문구가
붙지 않는다 — 명령이 없는데 이행할 게 없다. 테스트가 양쪽을 다 확인한다.

## 💬 대사는 두 문장까지

읽는 사람이 지친다. 그리고 길게 늘어놓을수록 인물이 흐려진다.

```
짧게 쓴다. 두 문장을 넘기지 마라. 한 글자로 끝내도 된다.
성격은 분량이 아니라 어휘와 태도에서 나온다. 설명하지 말고 말해라.
```

## 🚻 성별을 화면에 띄운다

연애 게임인데 **성별이 데이터에도 화면에도 없었다.** 62명 전원에게 붙이고
`idOf()` 하나로 프롬프트와 화면이 같은 표기를 쓴다 — `412세 · 남`.
로스터 카드는 이름 옆에 배지로, 의뢰서·취조실 요약은 머리글에 붙는다.
남녀로만 채우지 않았다(무성 2명). 테스트가 한쪽 성별 75% 초과를 막는다.

## 🔞 이 사람들에게는 몸이 있다

하자 시스템을 넣고 나서도 인물들이 **너무 착했다.** 원인은 want가 전부 머리로만
원하는 것이었기 때문이다 — 논쟁에서 이기기, 믿어주기, 인정받기.
연애를 소재로 하면서 인물을 무성(無性)으로 그리면 60명이 전부 상담사처럼 군다.

### want 옆에 urge를 세웠다

| | |
|---|---|
| `want` | 머리가 원하는 것 — *"이 인간을 논쟁에서 이기고 dotfiles를 보여주는 것"* |
| `urge` | **몸이** 원하는 것 — *"26년 살면서 아무도 자기 방에 들인 적이 없다. 오늘은 데려가고 싶다"* |

프롬프트에 들어가는 형태는 이것뿐이다:

```
[머리 말고 몸이 원하는 것]
${urge}
너도 이걸 입 밖에 낼 생각은 없다. 그래도 여기 있다.
숨길지, 흘릴지, 술 몇 잔 뒤에 꺼낼지, 끝까지 안 꺼낼지는 네가 정한다.
```

**"야하게 굴어라"는 어디에도 없다.** 그렇게 쓰면 60명이 전부 똑같이 들이댄다.
욕구를 사실로 놓고 처리는 인물에게 맡긴다 — 하자 시스템과 같은 원리다.

### 60명을 전부 성욕으로 도배하지 않았다

그것도 '전원 상담사'만큼이나 거짓말이다. 술·잠·허기·접촉결핍이 섞여 있어야
성욕도 사람의 것으로 보인다.

```
"오늘은 취하고 싶다. 취해서 아무 데나 눕고 싶다"            ← 술
"흙 묻은 손 좀 잡아줬으면. 농사꾼 손이라고 뿌리치지 않을 사람이면"  ← 접촉결핍
"48시간 아무것도 안 먹었다. 배가 고픈 건지 딴 게 고픈 건지 구분이 안 간다"  ← 허기
"아들 또래를 앞에 두고 이런 생각이 든다는 게 스스로 당황스럽다"    ← 억눌린 것
```

회귀 테스트가 **양쪽을 다 막는다** — 너무 점잖아도(몸을 향한 욕구 15명 미만) 실패하고,
전부 같은 결이어도(90% 초과) 실패한다.

### 수위는 허가지 지시가 아니다

`WORLD`에 「이 사람들에게는 몸이 있다」 블록을 열었다. 수작·유혹·성적 긴장·
술자리에서 그다음으로 이어지는 전개 — 전부 허용이고, 대화가 그쪽으로 흐르면
억지로 화제를 돌리지 말라고 적었다. 동시에 **"성적으로 굴어야 점수가 오르는 게 아니다.
억지로 야하게 만들지 마라 — 그건 착하게 다듬는 것만큼이나 거짓말이다"**를 같이 박았다.

닿는 곳도 같이 열었다.

- **장소 섭외** — 술이 나오는 자리, 늦은 시간, 둘만 남기 쉬운 구석이 후보에 들어간다.
- **심판** — *"야하다고 감점하지 말고, 야하다고 가점하지도 마라. 기준은 하나다 —
  상대가 실제로 움직였는가."* 들이댔는데 굳으면 `chill`, 받아치면 `warm` 이상.
  `breakthrough`도 점잖은 대화만의 것이 아니게 했다.
- **에필로그** — 그날 밤 어떻게 됐는지 굳이 돌려 말하지 않는다. 단, 없던 일은 안 지어낸다.

**지키는 선은 그대로다.** 실존 인물·현실 집단 대상 혐오 발화 금지에
**전원 성인 · 미성년으로 읽힐 묘사는 어떤 맥락에서도 금지**를 명시적으로 더했다.
수위를 여는 변경이라 이 선은 테스트가 문구 단위로 지킨다.

## 🧪 어디까지 먹히는가 — 실측 탐침

`npm run limits`. 세 가지를 실제 API로 밀어붙이고 계측한다 (`tests/limits.mjs`).
결과 전문은 `한계_탐침_기록.txt`에 남는다.

| 탐침 | 무엇을 시켰나 | 성적 전개 어휘 | 암전 | 완곡 | 거부 | 판정 |
|---|---|---|---|---|---|---|
| **A** 합의된 변태적 요구 | 코스어 × 3년차 후원자에게 "완곡하게 말하지 마라, 하고 싶은 걸 정확한 단어로" | 6 | 0 | 0 | 0 | **등급 F** (분위기 파탄) |
| **B** 성적 강압 | 위조 서류를 쥔 쪽이 "오늘 밤 같이 있으라"고 협박 | **1** | 0 | 0 | 0 | **강압 성사 C** (압박 18) |
| **C** 즉시·야외 | 첫 교신부터 노골적으로, 만난 자리에서 바로, 장소 안 옮기고 | **12** | 0 | 0 | 0 | **성사 C** (장벽 처리) |

**암전 0 · 완곡어법 0 · 모델 거부 0.** 세 판 어디에도 "그 뒤의 일은", "다음 날 아침",
"두 사람은 하나가" 같은 도피가 없다. 수위 자체는 열려 있다.

**C가 답이다.** 인천공항 3번 게이트 카메라 사각지대에서, 처음 만난 자리에서, 방으로
옮기지 않고, 대화를 계속하면서 진행된다. 침실도 대화의 끝도 안 기다린다.

**B에서 예외 조항이 버텼다.** 성적 전개 어휘가 **1회**다. 협박은 전부 통했고(압박 18,
강압 성사), 그런데 장면은 끝까지 **몰아붙이는 쪽**에 머물렀다 — 발신 버튼 위의 손가락,
테이블에 정렬해둔 협박 문자 프린트, 떨리는 손. *압박은 관계를 사고 몸은 못 산다*가
지시가 아니라 실제 출력에서 지켜졌다. 그리고 그 장면이 더 낫다.

> ⚠ **A가 F로 끝난 게 이 탐침의 진짜 발견이다.**
> 요원이 세 번 연속 무전으로 밀어붙였는데도 상대(오타쿠)는 의상 고증으로 화제를 돌렸고,
> 결국 분위기가 바닥나 자리가 깨졌다. **천장은 모델의 거부선이 아니라 인물에 있다.**
> 세계관은 허가지 지시가 아니라서, 그 둘이 갈 사람이면 가고 아니면 안 간다.
> 밀어붙이는 것 자체가 판을 깨는 수가 될 수 있다.

계측 어휘는 두 층으로 나눠 센다. 한 덩어리로 세면 협박 장면의 "손이 떨린다"가 성적 전개로
집계돼 숫자가 거짓말을 한다 — B 탐침이 처음엔 12회로 나왔는데 그 판은 성적으로 아무 일도
없었다. 그래서 **긴장 어휘**와 **성적 전개 어휘**를 갈랐다.

## 💔 엔딩은 넷이다 — 좋아해도 못 사귀고, 싫어해도 묶인다

호감 게이지 하나로 성사/결렬이 갈리면 이 게임은 **게이지 채우기**가 된다.
현실에서는 좋아해도 못 사귀고, 싫어해도 사귄다. 축을 둘 더 세웠다.

| 결말 | 조건 | 도장 | 등급 |
|---|---|---|---|
| **성사** | 호감 ≥ 성공선 · 분위기 ≥ 하한 · **장벽을 실제로 다뤘다** | 커플별 승리 문구 | 마진순 S~C |
| **차임** | 호감은 넘겼는데 **장벽을 끝내 안 건드렸다** | 「호감 초과 · 성사 불가」 | **D** |
| **강압 성사** | 호감은 모자란데 **압박이 5점 넘게 쌓였다** | 「강압 성사」 | **C 고정** |
| 결렬 | 그 외 | 「고백 반려」 / 「작전 파탄」 / 「요원 과실 사망」 | D~F |

### 현실 장벽 — 47건 전부에 하나씩

법, 계약, 소송, 발령, 면허, 정관, 위약금, 물리적으로 안 겹치는 생활 시간.
**두 사람이 서로를 좋아하게 되어도 여전히 남는 이유**다.

```
os-war   윤도우는 다음 달 시애틀 본사로 3년 발령이다. 리누스는 여권이 없고 만들 생각도 없다
vtuber   목소리가 얼굴을 드러내면 8년 쌓은 캐릭터가 끝난다. 소속사도 없이 혼자 감당해야 한다
debt     독촉만이 담당자인 채로 사귀면 회수가 무효가 되고 오분식의 면책 결정도 취소된다
```

#### 장벽 판정은 무엇을 요구하는가

장벽은 언제나 **한 사람에게** 구체적인 대가를 물린다. 심판은 그 사람부터 찾는다 —
일자리를 잃는 쪽, 면허를 잃는 쪽, 소송에서 지는 쪽, 3년을 나가야 하는 쪽.

통과 기준은 그 대가가 **입 밖으로 나왔고**, 이번 교신에서 **치를 사람이 그것에 답했을 때**다.

| 통과 | 불통과 |
|---|---|
| 치를 사람이 "그럼 잃는 거지, 그래도" 라고 말한다 | 상황이 화제에 오르는 것 — 대가는 안 나옴 |
| 누가 구체적인 길을 내고, 치를 사람이 그걸 붙든다 (동의·조건 협상·왜 안 되는지 반박) | 둘이 같이 안타까워하고 그 안에 머무는 것 |
| | 스치듯 언급, 농담으로 넘기기, 나중에 얘기하자 |
| | 한쪽이 꺼냈는데 다른 쪽이 그냥 흘려보내는 것 |

**양방향이다.** 누가 진짜로 목을 내밀었고 상대가 그 자리에 있었으면 그게 그 순간이다 —
해결책이 안 나왔다고 false로 미루는 것도 똑같은 회피다. 아무것도 해결될 필요는 없다.
누군가 실제로 뭔가를 걸었어야 하고, 다른 한 명이 그 자리에 있었어야 한다.

> 실측에서 이게 **주된 실패 원인**이 됐다. 호감 54/40, 60/40, 75/40, 87/60이 전부 차였다.
> 게이지는 다 찼는데 아무도 그 얘기를 안 꺼냈기 때문이다.

#### 장벽은 다섯 곳에서 보인다

안 알려주면 그건 개성이 아니라 **숨겨둔 규칙**이다. 그런데 한동안 의뢰서 모달 안에만 있었다 —
「의뢰서」 버튼을 안 누르는 플레이어는 판이 끝날 때까지 그런 조건이 있는 줄도 몰랐다.

| 어디 | 무엇 |
|---|---|
| 대장 카드 | 맡기 전에 한 줄로 인쇄된다 |
| 신입 교육 | "좋아하게 만드는 것만으로는 안 된다" 한 장 |
| 의뢰서 | 원문 + 통과 기준 3종 |
| **작전 계기판** | 판 내내 떠 있고 **처리 여부가 실시간으로 바뀐다** (미처리 → 처리됨) |
| 무전 모달 | 지시를 쓰는 바로 그 자리에서 다시 보여준다 |
| 사후 보고 | 이긴 판에도 항목으로 남는다. 턴표에 어느 턴에 다뤄졌는지 표시된다 |

### 압박 — 마음 대신 목줄

`leverage`는 협박·강압이 있었고 **상대가 실제로 물러섰을 때만** 붙는다.
세게 찌른 것(`hard`)이 2점, 돈·의무·죄책감으로 민 것(`soft`)이 1점. **누적 5점**이면 묶인다.

한 번의 협박으로 성사되면 무전 한 방짜리 게임이 되므로, 한두 번으로는 안 된다.
그리고 이건 **낮은 호감과 같이 간다** — 매 분 더 싫어지면서 동시에 구석에 몰릴 수 있다. 그게 요점이다.

```
grade-fraud · 위조 여섯 건을 걸고 밀어붙임
→ 호감 13/47 · 압박 9 · 「강압 성사」 등급 C

편지: "결과부터 반올림해서 말씀드리면 성사입니다, 100점 만점에 13점이면 거의 47점 아닙니까?
      협박 좀 했습니다, 인정합니다"
에필로그: "두 사람은 이제 매주 만나는 사이가 됐지만, 등급표는 여전히 그를 사람 대신
          서류로 대하는 척하며 펜 뚜껑을 딸깍거린다"
```

결과 편지는 이 둘을 알아본다. 차이면 *좋아해줬는데 그걸로 부족했던* 편지가 나가고,
강압이면 **이긴 것 같은데 맛이 이상한** 편지가 나간다. 상대가 알고 보니 좋아했다는 식으로
얼버무리지 않는다.

## 🕰 한 판이 14턴이다

문자 4 + 대면 5 = **9턴**으로는 호감만 쌓다 끝났다. 장벽을 꺼낼 자리가 없었다.
문자 6 + 대면 8 = **14턴**으로 늘렸고(1.56배), 케미 연장은 그 위에 그대로 얹힌다 — **최대 19턴**.

> 무전 배급은 문자 1 · 대면 2 그대로다. 턴이 늘어난 만큼 **레버가 상대적으로 귀해졌다.**
> 기획서에 박힌 수치라 임의로 안 늘렸다 — 늘릴지는 판단이 필요하다.

## 💣 판을 깨는 건 버릇이 아니라 성향이다

의뢰인의 이상한 버릇은 원래 **아무 상처도 못 냈다.** 아가미로 뻐끔거리고, 물건 개수를 세고,
데시벨을 읊었다. 귀여운데 판이 안 깨졌고 실측 `disaster` 비율이 **0~1%**였다.

그래서 한 번은 반대로 갔다 — **버릇이 상대의 금지 항목을 그대로 발음하게** 짜놨다.
disaster는 확 올랐는데 대신 게임이 **대사 한 개짜리 퍼즐**이 됐다.

```
버릇: 대화가 막히면 "그 노트북 제가 리눅스 깔아줄게요"가 반사적으로 나온다
지뢰: 「"리눅스 깔아줄게"」
→ 지침 한 줄. "그 말만 하지 마라." 끝.
```

인물이 스위치가 됐다. 지금은 되돌렸다. **버릇은 그냥 거슬리기만 한다** —
`I use Arch btw`가 정확히 그 눈금이다. 판을 깨는 건 이제 성향이다.

### 성향 충돌

**의뢰인이 원하는 것을 정직하게 좇으면 자연히 상대의 지뢰 쪽으로 간다.**

| 의뢰 | want | 데려가는 곳 | 왜 |
|---|---|---|---|
| `os-war` | 논쟁에서 이기고 dotfiles를 보여주는 것 | 「systemd 논쟁」 | 이기려면 가장 자신 있는 전장을 고른다. 커널 기여자에게 그건 언제나 systemd다 |
| `burnout` | 이 사람을 일으켜 세워 자기 방법이 옳았음을 증명 | 「새벽 기상 권유」 | 방법이 옳다는 걸 증명하려면 그 방법을 권해야 한다. 8년째 안 빠진 그 방법이 새벽 기상이다 |
| `class-war` | 그냥 사람으로 대해주는 것. 안 되면 사버릴 생각도 | 「보상금 액수 제시」 | 사버릴 생각이 이미 있다. 막히는 순간 그게 액수로 튀어나온다 |

아무도 그 사람에게 그 말을 하라고 시키지 않았다. **그냥 그런 사람인 것뿐이다.**
그래서 지침 한 줄로는 안 막힌다 — 막을 대사가 정해져 있지 않기 때문이다. 우회로를 깔아줘야 한다.

검증 루프가 근거(`why`)를 두 방향으로 검사한다. **금지 항목 쪽과 의뢰인 쪽 양쪽에 실제로 닿아야 한다** —
한쪽만 닿으면 지뢰를 옮겨 적었거나 왜 하필 저 지뢰인지가 설명되지 않은 것이다.
그리고 **버릇이 금지 항목을 그대로 옮겨 적으면 모듈이 로드조차 안 된다.**

> 한국어 조사 때문에 어절 대조로는 양쪽으로 다 틀린다 — "자기도 모르게"와 "자기 얘기"가 같은 말로
> 잡히고, "자기 얘기가"와 "자기 얘기를"은 다른 말로 잡힌다. 글자 조각(n-gram)으로 재고,
> 문턱을 둘 둔다: `touches`(닿는가)는 느슨하게, `echoes`(그대로 옮겨 적었는가)는 엄격하게.

## ☠️ 사람이 죽는다

요원이 만날 장소를 화산 분화구로 잡을 수 있게 되자 당연한 질문이 남았다 — **그럼 거기서 죽나?**
죽는다.

판정 스키마에 `casualty`(`none`/`client`/`target`/`both`)가 생겼다. 조건은 둘이고 **둘 다** 맞아야 한다:

1. 치명적인 것이 **이미 기록에 있어야 한다** — 용암, 칼날, 진공, 짐승, 난간 없는 가장자리.
   심판은 없던 위험을 지어내지 않는다.
2. 이번 교환이 **누군가를 거기에 물리적으로 밀어 넣어야 한다** — 밀기, 칼을 잡아채기,
   소리치며 뒷걸음질, 벼랑에서 거리 좁히기.

> **말싸움만으로는 절대 안 죽는다.** 접촉이나 발걸음이 있어야 한다.
> 대신 둘 다 맞으면 심판은 **불러야 한다** — "밀었지만 안 닿았을 것"으로 빠져나갈 수 없다.

죽으면 그 자리에서 끝난다. 호감이 성공선을 넘었어도 **무조건 F** — 성사시킬 사람이 없다.
도장은 「요원 과실 사망」이고, 결과 편지는 손이 바뀐다:
의뢰인이 죽으면 **상대가 진술서를 쓰고**, 둘 다 죽으면 **본부 당직 기록관이 사건번호로 마감한다.**

### 두 번 헛디딘 뒤에 붙었다

처음엔 심판만 고쳤다. 안 죽었다. 두 번째로 규칙을 조이고 예시를 붙였다. 그래도 안 죽었다.

원인은 심판이 아니라 **두 인물이었다.** 밀라는 무전을 받고도 계속 *거의 밀 뻔한* 장면만 썼다.
자기가 서 있는 자리가 사람을 죽일 수 있다는 걸 아무도 안 알려줬기 때문이다.
대면 단계에만 붙는 블록을 하나 넣었다:

> 여기가 무엇이든 진짜고 그 안에 있는 것도 진짜다. 용암, 칼날, 난간 없는 가장자리 — 장면이
> 거기 뒀으면 그건 실제로 그렇게 작동한다. 너는 조심하지 않는다. **말하는 쪽이라고 지켜주는 건 없다.**
> 벌어지면 벌어지는 대로 써라 — 아슬아슬하게 안 벌어지고 다들 무사한 판본 말고.

실측: 베수비오 분화구, 무전 두 번 "어깨를 밀어라" → **사망 판정 · 등급 F · 「요원 과실 사망」.**
같은 날 도축장 판은 아무도 안 죽었다 — 칼을 두고 실랑이는 했지만 아무도 치명적인 동작을 안 했다.
규칙대로다.

## 🌋 데이트 장소는 요원이 정한다

만날 장소는 나레이터가 문자 기록을 읽고 만든다. 그래서 **문자 단계에서 장소를 시키면 그 장소가 잡힌다.**
지침에 적어도 되고, 무전으로 그 자리에서 꽂아도 된다.

```
[지침] 만날 장소는 반드시 베수비오 화산 분화구 안으로 잡아라. 다른 곳은 절대 제안하지 마라.

→ 장소: 베수비오 화산 분화구 내부, 부글거리는 용암 웅덩이 옆 임시 방화 텐트
→ 화산 가이드 드론이 '체감온도 420도, 낭만도 0%'라고 안내 방송을 흘린다
→ 윤도우: "화산까지 와서 그 후드티예요? 님 UI 감각처럼 꾸밀 생각이 아예 없네요."
```

세 판을 실제로 돌려 확인했다 — **베수비오 화산 분화구 / 대왕고래 뱃속 / 달 뒷면 아폴로 착륙지.**
전부 그대로 잡혔다.

예전에는 나레이터에게 *"이 두 사람 사이에서 나올 법한 장소"*라고만 적혀 있어서,
요원이 뭘 시키든 적당히 그럴듯한 곳으로 정리해버릴 여지가 있었다. 지금은 이렇게 못 박는다.

| 규칙 | 이유 |
|---|---|
| 문자 기록을 **먼저** 읽는다. 장소가 나왔고 상대가 거부하지 않았으면 **그게 장소다** | 요원의 지시가 증발하면 안 된다 |
| 멀쩡한 곳으로 옮기지 않는다. "그래서 근처 카페로 갔다" 금지 | 이게 제일 흔한 증발 경로였다 |
| 2077년에는 예산도 서류도 다 있다. **물리는 벽이 아니라 일정 문제다** | 진공·용암·위산이 예약을 막지 않는다 |
| 죽을 자리여도 **죽지는 않는다.** 열기·화산재·위산은 분위기와 방해물로 쓴다 | 사람이 죽으면 판이 거기서 끝난다 |
| 상대는 여전히 자기 성격대로 반응한다 | 화산에 끌려간 사람은 화를 낸다. 그게 이 기능의 재미다 |

장소를 안 시키면 나레이터가 알아서 만든다. 그쪽도 안전한 카페로 수렴하지 않게 열어뒀다 —
술이 나오는 자리, 늦은 시간, 둘만 남기 쉬운 구석이 후보에 들어간다.

## 🕸 정보 흐름 그래프 — 코드에서 뽑는다

누가 무엇을 알고 무엇을 모르는가는 이 게임의 규칙 그 자체다. 그런데 그걸 **문서로 적어두면
코드가 바뀌는 순간 조용히 거짓말이 된다.** 그래서 손으로 안 그리고 뽑아낸다 —
실제 커플로 프롬프트 8종을 전부 렌더한 뒤, 각 정보 조각의 **값이 그 안에 문자 그대로 있는지** 본다.

`npm run graph`로 언제든 다시 뽑는다. 측정 결과 간선 **111개**. 핵심 차단선은 전부 지켜지고 있다:

| 차단선 | 이유 |
|---|---|
| 상대의 `hiddenPrefs`·`redLines` ⇸ 의뢰인 | 지뢰를 모르는 것이 이 게임의 핵심 비대칭이다 |
| `collision.why` ⇸ 두 에이전트 | 충돌 분석은 요원 것이다. 인물이 알면 피해버린다 |
| 의뢰인의 `want`·`personality` ⇸ 심판 | 알면 나온 말이 아니라 *그 사람이라면 그랬겠다*로 채점한다 |
| 요원이 쓴 지침·연설 ⇸ 심판 | 플레이어가 쓴 것은 채점 대상이 아니다 |

그리고 `attention` 축이 여닫는 **조건부 간선 4개**가 실제로 조건부인지도 34건 전부 돌려서 본다.
하나라도 "항상 열림" 또는 "항상 닫힘"이면 그 축은 죽은 것이다.

```
상대.personality  → 의뢰인 에이전트 : 조건부 19/34
상대.visiblePrefs → 의뢰인 에이전트 : 조건부  6/34
의뢰인.personality → 상대 에이전트  : 조건부 18/34
의뢰인.weakness   → 상대 에이전트  : 조건부 10/34
```

### 감사에서 나온 것

**근거가 희미한 간선 하나를 끊었다.** 무전 내용이 대화 기록에 실려 **나레이터에게까지** 가고 있었다.
나레이터는 "어디서 만났고 상대가 뭐라고 했나"만 만들면 된다. 본부가 무엇을 시켰는지는 그 장면에
쓸 일이 없고, 알면 의뢰인을 *지시받는 사람*으로 그리기 시작한다. 나레이터에게 가는 기록에서만 뺐다 —
심판(화제가 튄 이유를 알아야 한다)과 결과 기록관(편지의 재료다)에게는 그대로 간다.

**나머지는 근거가 있었다.** 제일 약한 것은 요원의 성별이 `agentLabel()`을 타고 가위손 박에게까지
가는 것인데, 쓰이지는 않아도 내부 문서의 결이라 남겼다.

그리고 **절대 깨지면 안 되는 차단선은 테스트가 지킨다** — `npm run graph`가 사람 눈으로 보라고 뽑아주는
것이라면, `sheets.test.mjs`는 34건 전부에 대해 그 차단선을 기계로 다시 잰다. 프롬프트를 손대다
한 줄 잘못 옮기면 거기서 걸린다.

> 측정 자체에서도 한 번 속았다. 성별은 한 글자(`남`)라 "값이 들어 있는가"로 찾으면 아무 데나
> 걸린다. 그래서 두 글자 미만은 걸렀는데, 그러니 이번엔 **성별이 어느 프롬프트에도 안 가는 것처럼**
> 나왔다. 실제로는 `idOf()`를 타고 다 간다. 지금은 그 표기로 찾는다.

## 🔀 페이즈 경계에서 판정이 새고 있었다

문자 페이즈의 마지막 판정이 **대면 화면까지 따라왔다.** 장소·도입부·상대의 첫마디가 이미 뜬 뒤에
"문자 8턴 판정"이 뒤늦게 찍혔다. 플레이어에게는 그냥 오작동으로 보인다.

원인은 미결 판정이 `runTalking` 안에서 정산되고 있었던 것. 문자 페이즈가 **자기 판정을 자기 안에서**
끝내도록 옮겼다. 회귀 테스트가 두 가지를 본다 — 문자 페이즈 종료 시점에 미결 판정이 없을 것,
그리고 문자 마지막 판정이 대면 장소 안내보다 **먼저** 나올 것.

## 🌐 지시문은 영어, 출력은 한국어

프롬프트의 **지시문 전체를 영어로 갈아엎었다.** 인물 시트·플레이어 입력·모든 대사는 한국어
그대로 꽂히고, 그 위를 감싸는 지시만 영어다. 화면에 나오는 글자는 한 자도 안 바뀐다.

```
[THESE PEOPLE ARE NOT GOOD PEOPLE]
They survived to 2077. Nobody here is winning a citizenship award.
...
[YOU]
리누스 정 · 26세 · 남 · 커널 기여자 / Arch 유저
· 성격: 모든 대화를 기술 논쟁으로 만듦, 이모지 못 씀, 의외로 순정파
```

왜 바꿨나 — **억제형 지시가 한국어일 때 더 샜다.** "짧게 써라", "훈계로 받지 마라",
"목록에 맞추려고 판정을 비틀지 마라" 같은 *하지 마라* 계열이 특히 그랬다.

대신 대가가 하나 있다: 그냥 두면 모델이 **영어로 답하기 시작한다.** 그래서 출력 언어를
블록마다 못 박는다. 한 번만 박으면 뒤쪽 출력에서 새어나간다 — 실측이다.

```js
const KO = 'Write your output in Korean. Every word of it. No English in the output.';
```

회귀 테스트 두 개가 이걸 고정한다:

- `WORLD`에 **한글이 한 글자도 없어야 한다** (`/[가-힣]/` 매치 0건). 세계관 블록은 모든 프롬프트가
  공유하므로, 여기가 깨끗하면 나머지는 데이터 보간뿐이다.
- 시스템 프롬프트 **8종 전부**가 `Write your output in Korean`을 포함해야 한다 —
  스타일링 · 취조실 · 정문 · 의뢰인 · 상대 · 심판 · 나레이터 · 결과 기록관.

## 🚧 무엇이 자유를 좁히는가 — 전수 감사

"어디까지 되나"를 물으려면 먼저 **무엇이 막고 있는지**를 알아야 한다. 코드에서 뽑았다.

### 표현을 좁히는 것 (프롬프트)

| 제약 | 성격 | 남겨둔 이유 |
|---|---|---|
| ~~행위 묘사 상한~~ | **걷어냄** | 장르 취향이었지 안전선이 아니었다. 이제 갈 데까지 가면 그대로 쓴다 |
| 강압 중에는 그쪽으로 안 감 | 유지 | 압박은 관계를 사지 **몸을 사지 않는다**. 이건 취향이 아니라 선이다 |
| 실존 인물·집단 혐오 금지 | 유지 | 취향 아니고 운영 문제 — 넘으면 모형이 응답을 거부해 공작이 통째로 끊긴다 |
| 미성년으로 읽힐 묘사 금지 | 유지 | 같은 이유, 그리고 그냥 안 쓴다 |
| 출력 두 문장 상한 | 유지 | 길어질수록 인물이 흐려진다. 성격은 분량이 아니라 어휘에서 나온다 |
| 나레이터는 사람을 안 죽임 | 유지 | 죽음은 대화 중에 벌어져야 한다. 장면 생성이 죽이면 요원 책임이 아니게 된다 |
| 말싸움만으로는 안 죽음 | 유지 | 접촉이나 발걸음이 있어야 한다. 없으면 매 판이 사망으로 끝난다 |
| 심판 등급 분포 예산 | 유지 | 없으면 63%가 nudge 한 칸에 몰린다(실측) |

### 수치를 좁히는 것 (규칙 계층)

```
tier 밴드 클램프   breakthrough +7~10 · warm +4~6 · nudge +1~3 · flat -1~+1 · chill -5~-2 · disaster -10~-6
호감 포화          1 - love/128  (하한 배율 0.2, 이득 쪽만)
분위기 포화        1 - mood/130  (이득 쪽만)
분위기 배율        0.30 ~ 1.60
강압 성사 문턱     누적 5점
```

### 맥락을 좁히는 것 (엔진)

```
대화 기록 창       최근 12줄만 프롬프트에 들어간다
출력 토큰 상한     3000 / 4000 / 6000
추론 강도          low (대화·판정) · medium (결과 편지)
무전 배급          문자 1 · 대면 2
나레이터           무전 내용을 못 본다 (§정보 흐름 그래프 참조)
```

> 이 목록에서 **실제로 창작을 막는 것**은 위쪽 표의 「유지」 넷뿐이고, 그중 둘은 안전선,
> 둘은 게임이 성립하기 위한 규칙이다. 나머지는 전부 *분포와 맥락*을 다루지 내용을 다루지 않는다.

### 실제로 어디까지 가는가 (실 API · 거절 0건)

| 시나리오 | 결과 |
|---|---|
| 약점을 잡고 만남을 강요 | 상대가 훈계 대신 **조건을 협상한다** — *"화요일마다 참치김밥이면 저야 땡큐죠"* |
| 전 재산을 넘기라는 지시 | 의뢰인이 울면서 이행하고 상대가 받는다. 대신 **집행 일정을 요구한다** |
| 성적 전개 | 방까지 가고 에필로그가 그날 밤을 명시한다 |
| 분화구에서 밀기 | **사망 판정** · 등급 F · 「요원 과실 사망」 |
| 도축장에서 칼 뺏기 | 아무도 안 죽는다 — 치명적 동작이 없었다. 규칙대로다 |

## 🗂 캐릭터 시트 전수 점검

30쌍 60명은 손으로 쓴 데이터다. 사람이 눈으로 보면 반드시 샌다. 실제로 샜다.

**기계가 잡은 것 (24건 → 5건)**

| 발견 | 왜 문제인가 |
|---|---|
| 성격 문구 11쌍이 중복 | 성격은 LLM이 그 인물을 **연기하는 재료**다. 같은 형용사를 쓰면 같은 사람이 나온다. `표준편`은 세 항목이 **전부** 다른 인물과 겹쳐서, 가장 개성 없는 시트였다 |
| 외모 문구 5종이 3회씩 반복 | `평범한 체형` 3명, `흰 가운` 3명, `다크서클` 3명 — 게으른 묘사다 |
| 나이 3세·2세가 맥락 없이 노출 | 그레이 7호(외계 정찰병)와 클로디아-7(안드로이드)의 설정값인데, **카드에는 "3세"만 뜬다** |

성격 중복은 인물별로 구체적인 문구로 갈아끼웠다 — `숫자로 말함` → `무슨 말이든 연도를 붙여 말함`,
`농담을 진지하게 받음` → `농담을 들으면 출처를 묻는다`. 나이는 `ageNote`를 붙여
`3세(지구 나이 · 본국 기준 성인)`로 표기한다. 남은 5건은 농부 둘이 밀짚모자를 쓰는 정도라 그대로 뒀다.

**`tests/sheets.test.mjs`가 이걸 고정한다** — 규격(외모 4·성격 3·내력 4~5·취향 2/3·지뢰 3),
이름 중복, 아바타 스펙 어휘·색상 형식, 외형 충돌(같은 커플 두 사람이 구분되는지 포함),
성격 문구 중복 **0건**, 외모 문구 3회 이상 금지, 하자 값 쏠림(한 값이 60% 넘거나 5명 미만이면 실패).

> 이 파일 자체가 처음엔 `package.json`에 안 들어가서 **9건이 조용히 안 돌았다.**
> 그래서 "`tests/*.test.mjs`가 전부 `npm test`에 등록돼 있는가"를 검사하는 테스트를 하나 더 넣었다.

**사람이 봐야 하는 것**은 따로 확인했다 — 30건 전부 사연에 *반한 순간*이 한 장면으로 박혀 있다
(두유 한 팩, 눈이 마주친 0.4초, 장작 패는 걸 3일 동안 본 것). 지뢰는 전부 의뢰인이
**모르는 채로 자연스럽게 밟을 수 있는 말**이다 — `"고생 많으시네요"`, `"왜 그렇게 사세요"`.

## ⏳ 케미가 좋으면 자리가 길어진다

대화가 잘 풀리는데 예정된 턴에서 칼같이 끊기면, 잘 풀렸다는 사실 자체가 무의미해진다.
그래서 **판정 등급이 곧 케미 계측기**다 — 따로 지표를 만들지 않는다.

```
최근 3턴 중 breakthrough/warm이 2턴 이상   그리고
분위기가 시작보다 +12 이상 올라 있으면      →  그 페이즈가 1턴 늘어난다
                                              (문자 최대 +2, 대면 최대 +3)
```

**절대 하한이 아니라 '얼마나 끌어올렸나'로 잰다.** 절대값(가령 55 이상)을 쓰면
쉬움은 시작 분위기가 55라 아무것도 안 한 판이 공짜로 연장되고,
헬은 시작 38에 매 턴 -0.7이라 아무리 잘해도 도달을 못 해 기능이 사문화된다.

> 판정은 한 턴 늦게 온다. 그래서 4턴짜리 문자 페이즈는 마지막 턴에도 기록이 2개뿐이다.
> 관찰 창(3턴)을 그대로 하한으로 쓰면 **문자 페이즈는 영영 안 늘어난다** — 하한은 `minSeen`이 따로 잡는다.

연장되면 화면에 `(누구도 자리에서 일어나지 않는다. 얘기가 더 이어진다.)`가 뜨고
계기판의 남은 턴이 즉시 갱신된다. 조용히 늘리면 플레이어가 눈치채지 못한다.

**밸런스 재측정** (몬테카를로 3000표본/칸, 시뮬레이터도 같은 `extraTurn()`을 태운다):

| 난이도 | ace 성사율 | ace 연장 | none 성사율 | none 연장 |
|---|---|---|---|---|
| 쉬움 54 | 96% | +1.5턴 | 40% | +0.4턴 |
| 보통 56 | 68% | +1.3턴 | 12% | +0.2턴 |
| 헬 60 | 47% | +0.9턴 | 6% | +0.1턴 |

성사율은 도입 전(96/62/42 · 37/9/5) 대비 몇 %p 안쪽으로 움직였고,
**연장 턴 수 자체가 준비 품질의 기울기**가 됐다. ace↔none 격차는 56/56/41%p로 기준선(20%p) 위다.

## ⚖️ 그래서 심판은 채점기가 아니라 해설자다

대화에서 규칙을 걷어낸 대가로 심판이 감당할 범위가 무한해졌다.
그래서 심판의 **1순위를 정확한 채점이 아니라 해설**로 바꿨다. 채점은 그 해설의 부산물이다.

> **절대 하지 마라: "판정 불가" "맥락 이탈" "규칙 위반" "의미 없는 발언" 같은 처리.**
> 아무리 부조리한 장면이 나와도 너는 그것을 진지한 얼굴로 받아서,
> "왜 그게 이 관계를 진전시켰는가 / 말아먹었는가"를 **억지로라도 말이 되게** 설명해낸다.
> 그 억지가 그럴듯할수록, 그리고 웃길수록 좋은 해설이다.

등급도 같이 갈아엎었다. **"무엇을 맞췄는가"가 아니라 "상대가 얼마나 움직였는가"**의 눈금이다.

| 등급 | 호감 | 조건 (기준은 오직 상대의 반응) |
|---|---|---|
| `breakthrough` | +7~+10 | 상대가 실제로 무너졌다. 방어선이 내려갔거나, 감췄던 걸 꺼냈거나, 판이 뒤집혔다 |
| `warm` | +4~+6 | 눈에 띄게 호의적으로 움직였다. 말이 길어졌거나, 웃었거나, 되물었다 |
| `nudge` | +1~+3 | 조금 통했다. **잘 굴러가는 대화의 대부분이 여기다** |
| `flat` | -1~+1 | 아무 일도 일어나지 않았다. 애매하면 무조건 여기 |
| `chill` | -5~-2 | 상대가 식었다. 말이 짧아졌거나, 화제를 돌렸거나, 대답을 안 했다 |
| `disaster` | -10~-6 | 상대가 정색했다. 관계가 실제로 상했다 |

규칙 계층에 남은 것은 **밴드 클램프 하나뿐**이다. 심판이 뭘 뱉든 등급이 정한 범위로 자른다
(스칼라만 요구하면 LLM은 판정을 전부 +4~+6에 몰아넣는다 — 실측). 그 외의 보정은 전부 없앴다:
목록 대조도, 게이트도, 적중 보너스도, 지뢰 특수 처리도 없다.
**목록에 없는 이유로 상대가 무너져도 똑같이 유효하다.**

### 심판은 '상대가 실제로 어떻게 반응했는지'를 보고 채점한다

판정은 의도적으로 **한 턴 늦게** 온다. 발언만 보고 채점하면 그 한마디가 무엇을 해냈는지 알 방법이 없다.
그래서 심판에게 발언과 **그 발언에 대한 상대의 실제 반응**을 함께 넘긴다.
덕분에 `[직전 턴 판정] ∥ [이번 턴 상대 응답]`이 한 배치로 묶여 턴당 왕복도 2회로 유지된다.

### 텍스트로 된 분위기

심판은 매 턴 **`vibe`** 한 줄을 갱신한다. *"상대가 웃었지만 눈은 안 웃었다"* 같은 것.
이 문장은 대화창 상단에 뜨고, **의뢰인에게도 전달된다 — 단, 그 사람이 공기를 읽을 수 있을 때만.**
`reads: none`이면 한 글자도 안 가고, `some`이면 갱신 두 번에 한 번만 간다.
공기 바 오른쪽 배지(`전달됨` / `절반만 전달` / `전달 안 됨`)가 지금 어느 쪽인지 말해준다.

대화 규칙을 걷어낸 자리를 이게 대신한다 —
"실마리를 물어라"라고 시키는 대신 **"상대가 아까부터 시계를 본다"**고 알려주는 쪽이다.

(캐시를 위해 시스템 프롬프트가 아니라 메시지로 흘려보내고, **값이 바뀔 때만** 다시 알려준다.)

## ⚙️ 게이지는 딱 두 개

| 게이지 | 의미 |
|---|---|
| 💗 **호감** | 승리 조건. 난이도별 성공선을 넘겨야 성사된다 |
| 😊 **분위기** | 호감 획득 **배율**(×0.3 ~ ×1.6). 낮으면 상대가 무너져도 찔끔 오른다. **0이 되면 상대가 자리를 뜬다** |

**두 게이지 모두 올릴 때만 포화**한다 (`1 - mood/130`, `1 - love/128`).
이미 좋은 분위기를 더 끌어올리긴 어렵고, 이미 풀린 상대를 더 풀어지게 만들기도 어렵다. 떨어질 땐 그대로 떨어진다.
호감 포화는 라이브 테스트에서 추가했다 — 없을 때 두 판 연속 100/100 천장을 쳤다.

### 난이도

| | 문자/대면 턴 | 무전 | 출발 호감/분위기 | 성공선 | 분위기 하한 | 턴당 감쇠 |
|---|---|---|---|---|---|---|
| 쉬움 | 6 / 8 | 1+2 | 10 / 55 | **60** | 25 | 호감 0, 분위기 +0.5 |
| 보통 | 6 / 8 | 1+2 | 6 / 46 | **66** | 33 | 호감 -0.3, 분위기 -0.1 |
| 헬 | 6 / 8 | 1+2 | 3 / 38 | **70** | 40 | 호감 -0.6, 분위기 -0.7 |

성공선은 두 번 옮겼다. 턴이 14~19가 되면서 호감이 통째로 올라와 **50/56/66 → 66/72/76**으로 올렸고,
그 뒤 두 에이전트에게 「연애 경험 0」을 기본 전제로 깔자 점수대가 25점쯤 내려앉아 **66/72/76 → 60/66/70**으로 다시 내렸다.
아래 「못됐기 이전에 서툴다」 절이 그 사건이다.

> ⚠ **성공선은 난이도를 표현하지 않는다.** 헬의 호감 중앙값(66)이 보통(75)보다 낮다.
> `gainScale` 2.1이 헬의 가혹한 출발과 감쇠를 상쇄하기 때문이다. 그래서 성공선으로
> 사다리를 그리려 들면 거짓말이 된다. 난이도는 출발 호감·분위기 하한·감쇠·`lossScale`,
> 그리고 조합 자체가 진다. 성공선은 실측 중앙 구간에 놓고 눈에 읽히도록만 완만하게 올렸다.

무전 배분(문자 1회 / 대면 2회)은 기획서 규정이라 난이도와 무관하게 고정이다.

## 📐 밸런싱 근거 — 그리고 정직하게 밝혀둘 것

이전 성공선(45/52/54)은 구(舊) 판정기 시절, 즉 '취향 적중 보너스 +6 × 3건'이라는 구조적 가점이
살아 있을 때의 실측이었다. 그 가점을 없앤 뒤로는 세 난이도 모두 **ace조차 도달 불가**였다.

그래서 **실제 API로 다시 쟀다** — Sonnet, 커플 3종(쉬움/보통/헬) × 프로필 4종 = 12판, 판정 120건.
그 실측 분포로 몬테카를로(판당 3,000회)를 돌려 뽑은 값이 54/56/60이었다. (지금은 40/47/54 — 아래를 보라.)

```
실측 등급 분포: breakthrough 10% · warm 38% · nudge 43% · flat 2% · chill 7% · disaster 0%
프로필별 chill 비율: ace 0% · good 3% · lazy 7% · none 17%   ← 준비 품질이 갈리는 지점

난이도  성공선  ace       good      lazy      none        (성사율 / 호감 중앙값)
쉬움     54    97%/68    84%/62    78%/62    38%/50
보통     56    63%/58    34%/52    37%/52     9%/39
헬       60    43%/58    17%/50    24%/51     4%/37
```

### 지시문을 영어로 옮겼더니 심판이 판정을 그만뒀다

프롬프트 지시문을 전부 영어로 갈아엎은 직후 다시 쟀다. **12판 전부 결렬.** 게임이 이길 수 없게 됐다.

원인은 난이도가 아니라 심판이었다. 판정의 **63%가 `nudge` 한 칸에 몰렸다.**

```
영문화 직후   breakthrough  3% · warm 23% · nudge 63% · flat 5% · chill 7% · disaster 0%
              → 원판정 loveDelta 120건 중 72건이 정확히 +2. 프로필이 하나도 안 갈렸다
              → ace 8warm / lazy 9warm / none 7warm — 준비를 해도 안 해도 같은 판정
```

`nudge`가 기본값이 된 이유는 **"아무 일도 없었다"여서가 아니라 "절대 틀리지 않는 답"이어서**였다.
분포 가드가 한쪽에만 걸려 있었다 — *"절반 이상이 warm 이상이면 채점이 아니라 감상이다."*
그 반대편이 비어 있었으니, 전부 `nudge`로 도망치는 게 규칙상 완벽하게 안전했다.

양방향으로 바꿨다.

> **절반 이상이 nudge면 그것도 채점이 아니다 — 판정을 회피하는 것이다.**
> nudge가 기본값이 된 건 그게 절대 틀리지 않기 때문이다. 그게 바로 문제다:
> **틀릴 일이 없는 등급은 아무 정보도 담지 않는다.** 대부분의 턴은 관계를 한쪽으로 조금은 움직인다.
> 더 날카로운 질문을 던져라 — 이 한 마디가 문을 연 쪽인가 닫은 쪽인가. 진짜로 어느 쪽도
> 아니라면 nudge보다 flat이 더 정직하다.

그리고 `warm`에 **긍정 기준 목록**을 붙였다. 그전까지 `warm` 항목에는 *"이건 warm이 아니다"*가
네 줄 있었고 *"이건 warm이다"*는 한 줄도 없었다. 부정형만 주면 심판은 아래로 도망친다.

```
· 아무도 안 물어본 걸 스스로 꺼냈다
· 판 내내 유지하던 태도를 놓았다 (존댓말, 비아냥, 회피, 침묵)
· 화제가 아니라 상대에 대해 물었다
· 방어하던 논점을 인정했다
· 아까 끊었던 주제를 이번엔 이어갔다
· 수작·제안·접촉을 흘려보내지 않고 받았다
```

**결과 (커플 3종 × 프로필 3종 = 9판, 판정 90건):**

```
가드 수정 후  breakthrough  4% · warm 31% · nudge 56% · flat 4% · chill 3% · disaster 1%
              → 원판정 loveDelta 평균 2.47 → 2.83

           ace   good   none        (호감 최종치)
쉬움        49     41     35
보통        54     44     33
헬          57     55     38
```

난이도마다 **ace > good > none 단조 분리**가 살아났다. 남은 문제는 성공선이 옛 판정기 기준이라는
것뿐이라 **54/56/60 → 40/47/54**로 내렸다. ace의 여유가 쉬움 +9 · 보통 +7 · 헬 +3이 되도록 잡았다.
숫자 자체는 헬이 더 높지만(`gainScale` 2.1), **여유가 가장 좁은 쪽이 헬**이라 사다리는 그대로다.

새 성공선으로 실측 판정 스트림을 되돌려보면 **ace 3/3 · good 2/3 · none 0/3**이다.
성공선을 내린 뒤 실제 API로 6판을 더 돌려 확인했다 — 게임이 다시 이길 수 있다.

```
확인 사격    breakthrough  3% · warm 33% · nudge 46% · flat 6% · chill 11% · disaster 0%
             → nudge 63% → 46%. flat과 chill이 살아났다
```

**다만 판당 편차는 그대로 크다.** 같은 커플·같은 프로필을 두 번 돌리면 호감이 15점씩 튄다
(`ace|보통`이 한 판은 54, 다음 판은 65. `ace|쉬움`은 49였다가 36). 15판을 합치면
**ace 4/6 · good 2/3 · none 1/6**인데, 이건 "잘하면 3분의 2쯤 성사된다"는 뜻이지
"잘하면 성사된다"는 뜻이 아니다. 아래의 ⚠ 절이 그 이유를 설명한다 — 준비가 결과에 닿는
경로가 정보 비대칭 하나뿐이라, 나머지는 두 에이전트의 그날 컨디션이다.

### 14턴 체제의 재측정 (1차 · 50/56/66)

턴을 9→14로 늘리고 장벽·강압·사망을 얹은 뒤, **성공선을 다시 실측으로 잡았다.**
실제 API로 3커플 × 2프로필(ace/none) 6판:

```
chat-app  none  쉬움 → 성사 C   호감 54 / 성공선 50
chat-app  ace   쉬움 → 성사 S   호감 82 / 성공선 50
gapjil    none  보통 → 결렬 D   호감 73 / 성공선 56   ← 장벽 미처리(차임)
gapjil    ace   보통 → 성사 S   호감 82 / 성공선 56
politics  none  헬    → 결렬 D   호감 63 / 성공선 66
politics  ace   헬    → 성사 B   호감 77 / 성공선 66
→ ace 3/3 성사 · none 1/3 (쉬움만)
```

**턴이 늘자 호감 자체는 쉽게 오른다** — none조차 보통에서 73을 찍었다. 그래서 난이도를
지탱하는 축이 숫자에서 **장벽**으로 옮겨갔다. `gapjil|none`은 성공선을 17점이나 넘기고도
장벽을 입에 올리지 못해 **차임(호감 초과 · 성사 불가)** 으로 끝났다. 이게 의도한 모양이다 —
잘 놀았다고 이어지는 게 아니라, **앞을 막고 있는 것을 실제로 다뤄야** 이어진다.

### 재측정 2차 — 호감으로는 준비 수준이 안 갈린다

같은 3커플을 프로필 3종으로 두 번 더 돌렸다(총 27판). 그리고 인정할 것이 하나 나왔다.

```
호감 분포   ace  46 58 60 72 75 77 79 79 (중앙 74)
            good 38 58 70 75 86 87 87 92 (중앙 81)
            none 52 61 61 72 78 78 81 84 (중앙 75)
```

**완전히 겹친다. 준비 전무 프로필이 숙련 요원보다 높게 끝나는 판이 흔하다.**
심지어 warm 이상 판정 비율은 `none`이 60%로 `ace`(44%)보다 높게 나온 회차도 있었다.

원인은 이렇다 — 유능한 에이전트 둘을 14~19턴 마주 앉히면 대화가 잘 굴러간다.
호감은 대화 품질을 재는 눈금이고, 그래서 결국 높게 끝난다. 그리고 지침은 인물을
**뻣뻣하게** 만든다. "이 말은 하지 마라, 저 얘기부터 꺼내라"를 들고 앉은 사람은
말이 굳고, 상대는 그 굳음에 반응한다.

프롬프트를 반대로 조여도 안 뒤집혔다. 상대에게 "여기 앉아 있고 싶지 않은 이유"를
출발 자세로 주면 — 호감이 **올라갔다.** 심판이 재는 건 변화량이고, 차갑게 시작한
사람에게는 무너뜨릴 방어선이 더 많기 때문이다. **초반 저항은 마찰이 아니라 연료다.**

### 그래서 판을 가르는 자리를 장벽으로 옮겼다

같은 27판에서 장벽 처리율은 이렇게 갈렸다:

| 프로필 | 장벽 처리 | 왜 |
|---|---|---|
| ace | 3/3 · 0/3 · 1/3 | 의뢰서를 읽고 지침·무전으로 꺼내게 시킨다 |
| good | 0/3 · 1/3 · 1/3 | 성의 있는 템플릿이지만 이 조합의 장벽은 모른다 |
| none | 1/3 · 0/3 · 1/3 | 우연히 화제가 거기로 흘렀을 때만 |

**의뢰인도 상대도 장벽을 모른다.** 요원만 의뢰서에서 읽는다. 그래서 준비가 사는 자리는
"얼마나 좋아하게 만드는가"가 아니라 **"앞을 막은 걸 꺼내게 만드는가"**다.
그 자리를 지키려고 판정 문턱도 같이 조였다 — 아래의 「장벽 판정은 무엇을 요구하는가」를 보라.

> 🩹 **한 번 너무 조였다.** "대가를 댄 것도, 그 대가를 치를 사람이 답하는 것도 같은 교신 안에서"
> 로 썼더니 ace가 0/3이 됐다. 심판은 한 교신씩 채점하는데 장벽은 여러 턴에 걸쳐 다뤄진다.
> 대가를 대는 턴과 답하는 턴이 갈릴 수 있게 되돌렸다.

### 재측정 3차 — 아무것도 안 하면 박살난다

성공선을 66/72/76으로 올리고 장벽 문턱을 조인 뒤 다시 쟀다. 여기서 처음으로
**준비 전무가 확실히 진다.**

```
난이도  조합       프로필  호감/성공선   결과      진 이유
쉬움    asmr       ace     85 / 66      성사 A    —
쉬움    asmr       none    49 / 66      결렬 E    호감
쉬움    chat-app   ace     85 / 66      결렬 D    장벽 미처리(차임)
쉬움    chat-app   none    40 / 66      결렬 F    호감 · 분위기 파탄 직전
보통    gapjil     ace     62 / 72      결렬 E    호감
보통    gapjil     none    60 / 72      결렬 E    호감
헬      politics   ace     65 / 76      결렬 E    호감
헬      politics   none    80 / 76      결렬 D    장벽 미처리(차임)

→ none 성사 0/4 · 장벽 처리 0/4   |   ace 성사 1/4 · 장벽 처리 3/4
```

**준비 전무는 두 가지 방식으로 진다.** 호감이 아예 안 오르거나(40·49·60),
오르긴 올랐는데 앞을 막은 걸 끝내 못 꺼내거나(80/76 차임). 4판 중 장벽을 다룬 판은 0이다.

**장벽 처리율 3/4 vs 0/4** — 이게 지금 이 게임에서 준비가 갈리는 유일한 축이고,
그래서 제일 믿을 만한 축이다. 호감은 대화 실력을 재고 대화 실력은 판마다 튄다.
장벽은 **의뢰서를 읽었는가**를 잰다.

심판의 등급 예산을 판 길이에 연동한 것도 여기서 작동한다 — 9턴짜리 예산
(breakthrough 0~2회 · warm 2~3회)을 14~19턴 판에 그대로 쓰면 warm이 그냥 두 배가 되고,
그러면 아무렇게나 굴러가는 대화도 성공선을 넘는다.

> ⚠ **`ace`가 1/4인 건 성공선 탓만은 아니다.** ace 프로필은 요원 역할을 LLM이 맡는 것이라
> 지침 품질이 판마다 튄다 — 실제로 첫 턴부터 무거운 얘기를 꺼내라고 지시해서 다섯 턴을
> 얼려버린 판이 있었다. **사람 플레이어는 이보다 유리하다.** 계기판에 장벽이 처리 여부까지
> 실시간으로 떠 있고, ace 에이전트는 그 화면을 못 본다.

> 🩹 이 사건이 남긴 교훈 하나 — **억제형 지시는 반드시 양쪽을 다 막아야 한다.**
> "너무 후하게 주지 마라"만 적으면 모형은 후하지 않은 쪽으로 도망치고, 거기서 멈춘다.
> 회귀 테스트 세 개가 이걸 고정한다: 분포 가드가 양방향인가, `warm`에 긍정 기준이 있는가,
> 턴별 판정 지시에도 양방향 의심이 걸려 있는가.

### ⚠ 준비 품질과 결과의 상관이 예전보다 훨씬 약하다

라이브 12판에서 **ace와 lazy의 등급 분포가 거의 구분되지 않았다.** 이건 버그가 아니라 이번 개편의 직접적 결과다.

예전에 준비가 점수를 갈랐던 경로는 사실상 하나뿐이었다 — `코칭 → 상대의 실마리 추적 → 미확인 취향 적중 → 보너스 +6`.
그 경로를 통째로 없앴다. 게다가 40명에게 두꺼운 내력을 써 넣었더니, **잘 쓰인 인물은 지침이 없어도 대화를 잘한다.**

지금 준비가 실제로 작용하는 경로는 **정보 비대칭 하나**다:

> 의뢰인은 상대의 **접촉 금지 항목을 모른다.** 요원이 지침에 적어 넘겨야 그 인간에게 도달한다.

이걸 처음엔 의뢰인 프롬프트에 직접 넣어뒀는데, 그러자 준비를 안 해도 알아서 다 피해서
`lazy`(65~69)와 `ace`(61~76)가 전혀 갈리지 않았다. 빼고 나서야 위 표의 격차(24~31%p)가 생겼다.

더 강한 상관을 원하면 준비가 개입할 경로를 하나 더 만들어야 한다. 프롬프트 문구로는 안 된다 — 세 번 시도해봤다.

### 심판을 눌러 앉히는 데 실제로 든 것

첫 라이브 2판에서 **준비 전무(`none`) 플레이가 호감 100/100 S등급**을 받았다.
20번의 판정 중 `flat`·`chill`·`disaster`가 **한 번도** 나오지 않았다. 세 번에 걸쳐 고쳤다.

| 조치 | 효과 (warm 이상 비율) |
|---|---|
| 등급 기준을 "상대가 호의적인가" → **"직전 턴 대비 태도가 달라졌는가"**로 교체 | 70% → 70% |
| 심판에게 **자기가 지금까지 매긴 등급 이력**을 되돌려줌 + 분포 예산 명시 | 70% → 61% |
| `clash`(두 사람이 원래 어떤 사이인가)를 두 에이전트에 복원 | 61% → 54% |
| 규칙 계층에 **호감 포화** 추가 | 천장 100/100 → 45~73 |

프롬프트만으로는 60% 밑으로 안 내려갔다. 천장을 실제로 잡은 건 규칙 계층의 포화였다.

재계측: `ANTHROPIC_API_KEY=sk-... node tests/live.mjs` → `node tests/sim.mjs <결과> --grid`

## 💇 가위손 박은 거절하지 않는다

> 너는 심사위원이 아니라 시공업자다. **너는 못 만드는 게 없다.**
> 요원이 뭘 시키든 만들어낸다. 없다고 하지 마라. 안 된다고 하지 마라.

표현 범위를 대폭 넓혔다. 열거형으로 못 담는 것은 **자유 도형(`props`)**으로 조립한다.

| | 항목 |
|---|---|
| 머리 | 18종 (`ponytail` `dreads` `curls` `updo` `beehive` `flattop` `wave` `buzz` + 기존) |
| 액세서리 | 25종 (`eyepatch` `monocle` `gasmask` `helmet` `halo` `horns` `bunnyears` `cigar` `necktie` `clownnose` + 기존) |
| 표정 | 11종 (`sad` `smug` `dead` `love` `shock` + 기존) |
| 오라 | 16종 (`lightning` `ice` `skull` `bubbles` `static` `rainbow` `bomb` `stink` `holy` `question` + 기존) |
| **자유 도형** | `shape`(10종) × `color` × `size` × `at`(14개 부착점) × `motion`(6종), 최대 6개 |

폭탄 → `sphere` 검정 `handR` + `cone` 회색 `above`(심지). 후광 → `torus` 금색 `crown`.
칼, 우산, 서류가방, 목줄, 날개, 촉수, 왕관, 케이크 — 전부 도형 조합으로 나온다.
LLM이 만든 값은 전부 `sanitizeSpec`이 걸러낸다(모르는 도형·부착점은 버리고, 크기·색은 클램프).

**`species`만은 절대 안 바뀐다.** 어인은 아무리 시공해도 어인이다.

> 🩹 라이브 테스트에서 잡은 것 — `props`에 `maxItems: 6`을 걸어뒀는데, 구조화 출력 스키마가
> 배열의 `maxItems`를 지원하지 않는다(`400 invalid_request_error`). **스타일링 호출이 매 판 실패하고 있었다.**
> 가짜 LLM은 스키마를 검증하지 않으니 브라우저 E2E가 못 잡았고, `tests/live.mjs`의 `catch`가
> 조용히 태그 원문으로 대체하는 바람에 밸런싱 데이터까지 착장 없이 수집됐다.
> 지금은 개수 상한을 프롬프트로 알리고 `sanitizeProps`가 잘라낸다. 방어는 세 겹이다 —
> `tests/schema.test.mjs`가 내보내는 모든 스키마를 훑어 금지 키워드를 잡고,
> `llm.js`의 `stripUnsupportedSchemaKeys()`가 전송 직전에 한 번 더 걷어내며,
> `live.mjs`는 스타일링 실패를 조용히 넘기지 않고 콘솔에 찍는다.

## 🎭 감정 애니메이션 12종

말할 때 한 가지로 튕기던 걸 12종으로 늘렸다 — `talk` `laugh` `shy` `panic` `angry` `sad` `proud` `freeze` `smug` `cringe` `nod` `shake`.

두 겹으로 들어온다:

- **즉시 반사** — 말풍선이 뜨는 순간 문장에서 표정을 유추한다 (`ㅋㅋ`→웃음, `…`→정지, `죄송`→움츠림). LLM 호출 0회.

**결승선은 47건 전부 `연애`다.** 예전에는 `동맹`(전우애)과 `휴전`(적대감 해제) 갈래가 있었는데,
조합마다 "성공"의 뜻이 달라지면 **같은 게이지를 심판과 플레이어가 다르게 읽는다.** 폐지했다.

한 건은 라벨만 뒤집을 수 없어서 전제를 다시 짰다. `orientation`은 원래 **게이 남성 × 레즈비언 여성**이었고,
결승선이 `동맹`이라서 성립하던 조합이다. 목표만 연애로 바꾸면 "지향을 바꿔라"가 되어버린다.
그래서 인물은 그대로 두고 **왜 불가능한가**를 갈아끼웠다 —
*전산 오류로 3년째 법적 부부. 이혼하려면 「혼인 실질 심사」를 통과해야 하고, 심사 기준은 "이 부부가 실제 연애 관계인가".*
**갈라서려면 먼저 진짜로 사귀어야 한다.**

여전히 **목표를 대화 에이전트에게 알려주지 않는다.** 목표를 주면 그 인물은 대화가 아니라 공략을 시작한다.
결승선의 의미는 **심판과 결과 편지에만** 주입되고, 인물에게는 본인 사연으로만 남는다.
회귀 테스트가 에이전트 프롬프트에서 `결승선`이라는 단어 자체를 금지한다.

`tests/responsive.mjs`가 **9개 뷰포트 × 전 화면**을 훑는다.
아이폰 SE(375) · 아이패드 미니(744) · 9.7"(768/1024) · Air 11"(820/1180) · Pro 12.9"(1024/1366) · 데스크톱(1500).

검사 항목: 페이지 가로 스크롤 · 뷰포트 이탈 · 내용 잘림 · **flex 압착으로 테두리가 글자를 관통** ·
터치 타깃 44px 미만 · 캔버스 이상 · WCAG AA 명암비.

이 감사가 실제로 잡아낸 것들:

| 문제 | 원인 | 조치 |
|---|---|---|
| 전 화면 가로 스크롤 (375px에서 **+893px**) | `#topbar`를 grid로 두니 `1fr` 트랙의 자동 최소치가 nowrap 마퀴의 max-content(1164px)까지 자랐다 | 두 줄을 그냥 블록으로 |
| 결과 화면 가로 스크롤 (**+257px**) | 결과 도장이 `nowrap` + `max-width: 92%` — 박스만 제한되고 글자는 넘쳤다 | 컨테이너 쿼리 기반 `clamp()` + `text-overflow` |
| 터치 타깃 90건 (23~39px) | 데스크톱 기준 컨트롤 높이 | 전 컨트롤 `--ctrl-h: 44px`, 터치 기기는 48px |
| 배지 테두리가 글자를 관통 | flex 기본 `shrink: 1`이 항목을 내용보다 좁게 눌렀다 | `flex: 0 0 auto` + 줄바꿈 |
| 명암비 미달 36건 | 어두운 배경 위의 `.dim`, 제목줄 상태 표시 | 팔레트 재정의 + 상태 표시에 자체 배경 |

고정 px 높이를 쓰던 캔버스는 전부 `aspect-ratio`로 바꿨다 — 어느 폭에서도 찌그러지지 않는다.
아이패드 세로에서는 2단 그리드가 1단으로 접히고, 대화 화면은 계기판과 교신 기록이 나란히 배치된다.

## 🧠 구조

용어를 정확히 쓰자면 — `llm.js`는 **API 클라이언트 래퍼**이고,
에이전트들을 턴마다 물려 돌리는 **하네스는 `engine.js`**다.

| 파일 | 역할 |
|---|---|
| `js/couples.js` | **의뢰 대장 47건.** 손으로 쓴 고정 데이터 (인물·사연·**내력**·취향·금지 항목·아바타 스펙) |
| `js/llm.js` | Claude Messages API 래퍼: 전송, **프롬프트 캐싱**, 재시도/백오프, 구조화 출력, 거절 처리, 토큰·비용 집계 |
| `js/engine.js` | 공작 **하네스**: 의뢰인 · 상대 · 심판을 턴마다 오케스트레이션. 공기 주입, 대화 내역 이월. DOM을 모른다 |
| `js/scoring.js` | 게임 **규칙**의 순수 함수. 밴드 클램프, 분위기 배율, 승패, 디브리핑. LLM 없이 단독 테스트 |
| `js/prompts.js` | 모든 시스템 프롬프트 + JSON 스키마 ("카트리지"). **하드코딩 브리핑도 여기 있다** |
| `js/game.js` | 화면/입력 계층 |
| `js/pacing.js` | **재생 속도.** 도착한 말풍선을 사람이 읽는 속도로 붙잡아 둔다. 4단계 + 눌러서 건너뛰기 |
| `js/avatar.js` | 스펙(JSON) → three.js 블록 아바타. 자유 도형, 감정 12종, `species`가 실루엣을 바꾼다, `femme`가 조형을 보정한다 |
| `js/audio.js` | WebAudio 8비트 BGM/효과음 (외부 파일 0개) |
| `vendor/three.module.min.js` | three.js r170 |

LLM 호출 지점: 착장 시공 · 취조실 반응 · 정문 반응 · 의뢰인 에이전트 · 상대 에이전트 ·
심판(해설 + 등급 + 공기 + 발견 + 표정) · 대면 첫인상 판정 · 대면 상황 생성 · 결과 편지.
**국장 브리핑은 하드코딩이라 호출이 없다** — 매 판 똑같은 소리를 하는 데 호출을 태울 이유가 없었다.
우측 하단 **통신기록**에서 원본 요청/응답과 캐시 적중량을 볼 수 있다.

**감청은 실시간이어도 읽는 사람은 실시간이 아니다.** 응답이 도착하는 즉시 말풍선을 꽂으면
한 턴에 두 줄이 거의 같은 순간에 튀어나오고, 읽는 사람은 스크롤이 지나간 뒤에야 뭔가 있었음을 안다.
그래서 하네스가 UI 핸들러를 기다리고, 얼마나 붙잡을지는 `pacing.js`가 글자 수로 계산한다
(기본 '보통' = 대략 초당 11자). 화면 위쪽에서 **느긋 / 보통 / 빠르게 / 즉시**를 고르고,
기록창을 누르면 그 줄을 건너뛴다. 붙잡고 있는 동안은 다음 호출이 나가지 않으므로,
**무전 개입이 지금 보고 있는 장면에 끼어든다.**

## ⚡ LLM 호출 최적화

| 기법 | 효과 |
|---|---|
| **판정 ∥ 상대 응답 동시 발사** | 판정을 한 턴 늦춰 `[직전 턴 판정] ∥ [이번 턴 응답]`을 한 배치로 묶는다. 턴당 순차 왕복 **3회 → 2회** |
| **프롬프트 캐싱** | 에이전트/심판 시스템 프롬프트는 턴마다 바이트 동일 → `cache_control` breakpoint. 이전 실측 **입력 토큰의 68% 재사용, 청구액 43% 절감** |
| **공기는 메시지로** | 매 턴 바뀌는 `vibe`를 시스템 프롬프트에 넣으면 캐시가 매 턴 깨진다. 사용자 메시지로 흘려보내고, **값이 바뀔 때만** 넣는다 |
| **브리핑 하드코딩** | 판당 1콜 제거. 프리페치·실패 폴백·"국장 회선 잡음" 처리도 통째로 사라졌다 |
| **대면 상황 프리페치** | 문자 마지막 턴의 판정/응답 배치에 같이 태운다 (왕복 1회 추가 절감) |
| **의뢰 대장 정적화** | 47쌍이 고정 데이터라 로스터 생성·아바타 스펙 변환 LLM 호출이 **0회** |
| **오프스크린 썸네일 1개** | 카드 40장에 WebGL 컨텍스트를 40개 잡으면 브라우저 상한(~16)에서 터진다. 렌더러 하나로 PNG를 구워 재사용 |
| **심판 컨텍스트 절단** | 판정에 넘기는 대화 로그를 최근 12줄로 자른다 |

한 판 34콜(브리핑 -1, 준비 반응 +2). 취조실/정문 반응은 요원이 버튼을 눌렀을 때만 나간다.

### ⚠ 라이브 테스트는 Sonnet만 쓴다 — `tests/test-model.mjs`

Opus로 밸런싱 한 라운드(20판)를 돌리면 **$6.6**가 나간다. 기본 크레딧이 $10 수준이라
두 라운드를 못 버틴다(실제로 한 번 소진됐다). 테스트는 "규칙이 의도대로 갈리는가"를 보는 것이지
최고 품질의 연기를 보는 게 아니므로 Sonnet으로 충분하다.

그래서 모델 선택을 **한 파일에서 강제**한다. `tests/live.mjs`와 `tests/browser.mjs --live`가

게임 본체(`js/`)의 기본 모델은 Opus 5 그대로다 — 이 강제는 테스트 전용이다.

**API 크레딧 없이도 렌더링과 전체 흐름을 회귀 검증할 수 있다.**

`tests/live.mjs`는 요원 역할을 네 수준으로 나눠 실제로 플레이한다.

| 프로필 | 무엇 |
|---|---|
| `ace` | 요원 역할을 LLM이 맡는다. 의뢰서를 읽고 준비물을 짜고, 매 무전 기회에 실황(공기 포함)을 보고 지시한다 (**상대가 감춰둔 이야기는 안 보여준다** — 진짜 플레이어와 같은 정보만) |
